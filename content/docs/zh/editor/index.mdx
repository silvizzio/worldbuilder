在线编辑器用于将三维重建成果制作成可交互、可预览、可分享的数字孪生应用。用户可以在同一浏览器工作区内完成模型摆放、业务标注、界面搭建、交互配置和项目发布。

传统三维交付流程通常需要在三维软件、说明文档和前端页面之间反复切换。WORLD BUILDER 将这些环节整合到在线编辑器中，使非工程人员也可以完成内容配置和演示交付。

## 工作区结构

在线编辑器由三维视口、功能面板、大纲、顶部工具栏和发布操作组成。三维视口用于查看场景效果，功能面板用于编辑具体对象，大纲用于定位场景中的模型、标记和界面内容。

| 区域 | 主要用途 |
| --- | --- |
| 三维视口 | 查看场景、调整视角、选择和检查三维内容 |
| 功能面板 | 配置场景、模型、标记、界面和插件能力 |
| 大纲 | 按层级查看项目中的模型、标记和界面页面 |
| 顶部工具栏 | 在场景、模型、标记、界面和插件之间切换 |
| 项目操作 | 保存、预览、分享和发布当前项目 |

## 功能面板

编辑器通过多个功能面板组织不同类型的配置。每个面板负责一个相对独立的内容层级，便于按流程搭建和维护项目。

| 面板 | 负责范围 | 常用角色 | 文档 |
| --- | --- | --- | --- |
| 场景面板 | 项目信息、相机控制、灯光和后处理 | 项目负责人、三维内容运营人员 | [场景设置](/worldbuilder/zh/docs/step-by-step-workflow/2-project-settings) |
| 模型面板 | 模型上传、摆放、显示/隐藏和调试 | 三维内容运营人员 | [上传模型](/worldbuilder/zh/docs/step-by-step-workflow/3-upload-models) |
| 标记面板 | 文本、图片、视频、数据标记和标记交互 | 解决方案工程师 | [添加标记](/worldbuilder/zh/docs/step-by-step-workflow/7-add-markers) |
| 界面面板 | 页面、组件、画布设置和组件交互 | 解决方案工程师 | [画布设置](/worldbuilder/zh/docs/editor/editor-panels/ui-panel/canvas-settings) |
| 插件 | 扩展编辑器能力，例如三维重建插件 | 三维内容运营人员、解决方案工程师 | [插件](/worldbuilder/zh/docs/plugins/) |

## 推荐工作顺序

建议按照“配置项目 → 上传模型 → 摆放模型 → 设置相机与灯光 → 添加标记 → 搭建界面 → 保存预览 → 发布分享”的顺序制作项目。

这个顺序与对象依赖关系一致。模型位置确定后再添加标记，可以避免标记偏移；目标页面和模型存在后再配置界面交互，可以减少无效引用和重复设置。

完整操作流程请参见[分步工作流](/worldbuilder/zh/docs/step-by-step-workflow/)。

## 与传统流程的区别

| 传统流程 | 在线编辑器 |
| --- | --- |
| 使用三维软件调整模型 | 在模型面板中直接摆放和调整 |
| 使用文档记录说明信息 | 将标记绑定到三维场景中的具体位置 |
| 由开发人员制作展示页面 | 通过界面面板搭建页面和按钮 |
| 修改后需要重新导出和部署 | 保存后即可预览，并可重新分享 |

在线编辑器的价值不只是减少工具数量，更重要的是缩短修改反馈链路。评审意见可以在同一项目中快速调整、保存和重新预览，使数字孪生内容具备持续迭代能力。

## 使用建议

在多人协作项目中，建议先由项目负责人完成项目类型和基础信息配置，再由三维内容运营人员完成模型导入与摆放，最后由解决方案工程师配置标记、界面和交互。这样可以避免后续内容依赖未定稿的基础配置。
