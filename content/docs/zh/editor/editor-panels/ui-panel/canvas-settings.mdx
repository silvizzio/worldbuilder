**画布**是用于编排界面元素的平面工作区，绘制在实时三维场景之上。

在持续变化的三维场景之上使用画布，会产生持续的细微干扰。在边缘附近拖动按钮会误移三维相机。背景场景与正在摆放的元素争夺注意力。误触发滚动会缩放视图，间距判断也随之改变。

本页的三项设置以同一方式解决同一问题：锁定当前不需要编辑的部分。它们改变编辑过程中画布的行为，不改变观看者在已发布项目中看到的任何内容。

## 字段参考

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 三维场景交互 | 画布是否允许鼠标与下方三维场景交互。 | 编辑界面图层时关闭，避免误改相机或场景。 |
| 三维场景渲染 | 界面画布之后的三维场景是否可见。 | 细化布局时隐藏，完整体验检查时重新显示。 |
| 画布缩放 | 编辑过程中界面画布是否可缩放。 | 精细布局时锁定，保持间距与对齐稳定。 |

## 启用或关闭三维场景交互

锁定与三维场景的鼠标交互，避免在编辑界面图层时改变视角或模型选中状态。

若不锁定，在画布边缘附近调整组件时容易误触发相机拖拽，导致场景移动，所依据的视觉语境随之改变。锁定交互可使该语境保持固定。

## 显示或隐藏三维场景渲染

隐藏三维场景渲染，以专注于页面与组件布局。当场景内容在编辑过程中与界面元素产生视觉竞争时，该功能较为适用。

评判最终效果前请重新开启渲染。与实际场景之间的对比度影响组件可读性，在空白画布上检查的界面，可能在编辑器中清晰、在已发布项目中难以辨认。隐藏用于摆放，显示用于评判。

## 锁定或解锁画布缩放

锁定画布缩放，防止编辑组件时误触发缩放。

稳定的缩放级别可保持设计视图一致，使组件间距更易准确判断。在确定版式或对齐多个元素时尤为重要，因为在一个缩放级别下判断、在另一级别下检查的间距会产生不一致的结果。
