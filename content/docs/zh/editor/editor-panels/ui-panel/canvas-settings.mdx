画布是用于编排界面页面和组件的二维工作区，覆盖在三维场景之上。编辑界面时，用户需要同时关注组件位置、可读性和三维背景关系。

画布设置用于控制编辑过程中的辅助行为，包括锁定三维场景交互、隐藏三维场景渲染和锁定画布缩放。这些设置只影响编辑体验，不会改变已发布项目中观看者看到的内容。

## 字段说明

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 三维场景交互 | 控制鼠标是否可以与画布下方的三维场景交互。 | 编辑界面组件时建议关闭，避免误操作相机或模型。 |
| 三维场景渲染 | 控制界面画布后方的三维场景是否可见。 | 精细排版时可隐藏，最终检查时应重新显示。 |
| 画布缩放 | 控制编辑过程中是否允许缩放画布。 | 对齐组件和调整间距时建议锁定。 |

## 锁定三维场景交互

锁定三维场景交互后，用户在编辑界面组件时不会误触发相机拖拽、场景旋转或模型选择。

当组件位于画布边缘，或需要频繁拖动按钮、图片和文本时，建议开启该设置。这样可以保持背景场景稳定，便于判断组件与三维内容的相对位置。

## 显示或隐藏三维场景渲染

隐藏三维场景渲染后，用户可以更专注地调整页面结构、组件对齐和文字排版。该功能适合在界面元素较多、背景画面干扰判断时使用。

完成布局后，应重新显示三维场景渲染，检查组件在真实背景下是否清晰可读。界面在空白画布上清晰，并不代表在发布场景中同样清晰。

## 锁定画布缩放

锁定画布缩放可以避免在编辑组件时误触发缩放操作，保持布局判断一致。

在调整组件间距、对齐多个元素或检查页面结构时，建议锁定缩放。这样可以避免因缩放比例变化造成视觉误判。
