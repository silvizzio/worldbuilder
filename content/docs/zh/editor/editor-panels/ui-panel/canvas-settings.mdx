画布设置控制界面图层与其下方三维场景之间的关系。

这三项都属于编辑辅助功能，而非输出设置。它们改变的是编辑过程中画布的行为，而不是已发布项目呈现给观看者的效果。三者背后的原则一致：锁定当前不需要编辑的部分。

## 字段参考

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 三维场景交互 | 画布是否允许鼠标与下方三维场景交互。 | 编辑界面图层时关闭，避免误改相机或场景。 |
| 三维场景渲染 | 界面画布之后的三维场景是否可见。 | 细化布局时隐藏，完整体验检查时再重新显示。 |
| 画布缩放 | 编辑过程中界面画布是否可缩放。 | 进行精细布局时锁定，保持间距与对齐稳定。 |

## 启用或关闭三维场景交互

锁定与三维场景的鼠标交互，避免在编辑界面图层时改变视角或模型选中状态。

若不锁定，在画布边缘附近调整组件时经常会误触发相机拖拽，导致场景移动，你所依据的视觉语境也随之改变。锁定交互能让这一语境保持固定。

## 显示或隐藏三维场景渲染

隐藏三维场景渲染，以便专注于页面与组件布局。当场景内容在编辑过程中与界面元素产生视觉竞争时，这一功能尤为有用。

在评判最终效果前请重新开启渲染。与实际场景之间的对比度本身就是组件是否清晰可辨的一部分，因此在空白画布上检查的界面，可能在编辑器中显得清晰，在已发布项目中却难以辨认。隐藏用于摆放，显示用于评判。

## 锁定或解锁画布缩放

锁定画布缩放，防止编辑组件时误触发缩放。

稳定的缩放级别能保持设计视图一致，也让组件间距更容易被准确判断。这在最终确定版式或对齐多个元素时尤为重要，因为在某一缩放级别下判断、又在另一级别下检查的间距，结果必然不一致。
