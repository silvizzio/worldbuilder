界面组件交互用于让二维界面控制三维场景。通过交互配置，按钮等组件可以触发相机飞行、显示或隐藏界面页面，也可以控制指定模型的可见状态。

未配置交互的组件只承担展示作用。配置交互后，界面可以成为导览、说明和操作控制入口，帮助观看者按照预设流程浏览项目。

## 交互类型

在组件属性中打开**交互面板**，选择**添加交互**后，可为当前组件配置一个或多个动作。

| 动作 | 点击后的效果 | 适用场景 |
| --- | --- | --- |
| 飞行到视角 | 将相机移动到预设位置 | 导览路线、产品演示、空间检查 |
| 显示或隐藏界面 | 控制指定页面显示或隐藏 | 多步骤说明、弹出信息、流程切换 |
| 显示或隐藏模型 | 控制指定模型显示或隐藏 | 分层讲解、前后对比、内部结构展示 |

## 飞行到指定视角

飞行到视角适合将观看者引导到关键位置。配置时需要设置目标相机位置、注视目标和飞行时长。

如果一个页面中包含多个导览按钮，建议保持相近的飞行时长和命名方式，例如“查看入口”“查看设备”“查看内部结构”。这样可以让观看者形成稳定的操作预期。

## 显示或隐藏界面

显示或隐藏界面用于控制页面之间的切换。常见做法是点击按钮后隐藏当前页面，并显示下一步页面，从而形成分步导览流程。

该功能也适合制作说明面板、弹出信息和临时控制项。只展示当前相关的内容，可以降低界面复杂度，避免遮挡三维场景。

## 显示或隐藏模型

显示或隐藏模型用于控制场景中指定模型的可见状态。该动作适合分阶段讲解模型结构、展示外壳与内部构件关系，或对比不同方案状态。

配置该动作前，应确认目标模型已经存在且命名清晰。若后续删除或重命名模型，需要同步检查相关组件交互。
