为界面组件附加动作，可使界面驱动三维场景。组件能够移动相机、切换页面或控制模型显隐。

若不附加动作，观看者需要手动导航并自行查找内容。这种方式适用于自由探索，但不适用于演示。


## 交互的配置方式

每个组件的属性中都有**交互面板**。使用**添加交互**附加动作，并从下拉菜单中选择类型。组件可承载多个交互，依次列为「交互 1」「交互 2」等。

| 动作 | 点击后的效果 | 适用场景 |
| --- | --- | --- |
| 飞行到视角 | 在设定时长内将相机移动到预设视角 | 引导式导览、产品演示、预先规划的空间顺序 |
| 显示或隐藏界面 | 显示或隐藏指定的界面页面 | 多步骤演示、语境信息展示 |
| 显示或隐藏模型 | 显示或隐藏指定模型 | 分阶段讲解、前后对比、简化复杂场景 |

**飞行到视角**动作需设置目标位姿的相机参数，以及控制过渡效果的时长。在一组按钮之间保持时长一致，可使漫游节奏统一。

## 飞行到指定视角

添加飞行到视角动作，使点击组件时相机移动到预设视角。

该动作使观看者可直接跳转至重要资产、区域或检查角度，适用于引导式导览、产品演示，以及需要观看者按既定顺序推进而非自由探索的流程。

## 显示或隐藏界面

添加显示或隐藏指定界面页面的动作，控制每个步骤中可见的内容。

仅展示当前相关的页面可减少界面杂乱，使各阶段更易理解。这是多步骤演示的实现机制：按钮通过隐藏当前页面、显示下一页面推进流程。

## 显示或隐藏模型

根据业务流程、场景状态或演示步骤，添加显示或隐藏指定模型的动作。

该动作可将注意力集中在当前重要的资产上，支持分阶段讲解、前后对比，以及通过隐藏外壳展示内部构件，后者通常是说明装配关系的最清晰方式。
