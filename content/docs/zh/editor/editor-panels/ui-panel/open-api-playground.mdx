Open API 演练场位于界面面板中，用于调试 WORLD BUILDER Viewer 与外部 WebUI 之间的开放 API。用户可以选择方法、填写参数、运行调用，并查看返回结果和对应代码。

演练场中的操作仅在当前会话中生效，不会写入项目保存内容。刷新 Viewer 后，模型、标记和界面显示/隐藏等运行时状态会恢复为项目配置中的状态。

## 方法列表

左侧区域列出当前可调用的方法，并提供搜索框。方法按能力分组，便于快速定位。

| 分组 | 方法 |
| --- | --- |
| 会话 | `handshake`、`scene.getInfo` |
| 相机 | `camera.getState`、`camera.getControllerMode`、`camera.setControllerMode`、`camera.reset`、`camera.flyTo` |
| 模型 | `model.list`、`model.getVisibility`、`model.show`、`model.hide`、`model.setVisibility` |
| 标记 | `poi.list`、`poi.setVisible`、`poi.flyTo` |
| 界面 | `ui.list`、`ui.show`、`ui.hide` |

其中，POI 指兴趣点，对应编辑器中创建的标记。

## 运行调用

1. 在方法列表中选择要调试的方法。
2. 在右侧**调试输入**区域填写 JSON 参数。无需参数时保持 `{}`。
3. 点击 **Run** 执行调用。
4. 在响应区域查看返回结果。

## 代码片段

演练场会根据当前选择的方法和参数生成等效代码，并提供复制按钮。

```js
const client = createTwinScapeClient({
  targetWindow: window.parent,
  targetOrigin: window.location.origin,
});
await client.ready();
await client.call('camera.getState', {});
```

建议先在演练场中调通接口，再复制代码到业务系统中使用。这样可以减少手写参数或方法名带来的错误。

## 请求与事件

右侧底部提供**请求**和**事件**两个标签，并支持清空记录。

**请求**用于记录每次 API 调用的时间、方法、参数和响应内容。`scene.getInfo` 的返回结果示例如下：

```json
{
  "sceneId": "indoor",
  "ready": true,
  "projectId": "22"
}
```

**事件**用于记录 Viewer 主动推送的消息，例如场景加载完成事件。事件不是用户主动发起的请求，而是 Viewer 状态变化后的通知。

## 模型与标记列表

方法列表下方会显示当前场景中的模型和标记，并提供刷新按钮。

| 列表 | 说明 |
| --- | --- |
| MODELS | 显示模型名称和 ID，并提供 show、hide、Fill 等快捷操作。 |
| POIS | 显示标记名称和 ID，并提供 flyTo、hide、Fill 等快捷操作。 |

这些快捷按钮会调用上方列表中的同名方法，并自动填入目标 ID。开发人员在编写集成代码前，可以先通过这些按钮确认 ID 与场景对象的对应关系。

## 连接状态

右侧顶部显示 Viewer 当前状态，例如 **Scene ready · indoor**。该区域还提供以下操作：

| 控件 | 说明 |
| --- | --- |
| Reload Viewer | 重新加载 Viewer，并清除当前会话中的临时状态。 |
| Reconnect SDK | 在不重新加载场景的情况下重新建立 SDK 连接。 |

当场景正常显示但 API 调用无响应时，可优先使用 **Reconnect SDK**。当需要恢复初始状态时，使用 **Reload Viewer**。
