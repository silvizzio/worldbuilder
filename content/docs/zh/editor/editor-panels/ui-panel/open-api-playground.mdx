**Open API** 位于界面面板中，处于画布设置与页面管理之间。

<ShotGrid images={['/demos/project-center/screens/ui-panel-canvas.png']} />

面板中说明这是用于相机、模型、POI 与界面图层的内嵌 API，并明确指出改动仅在当前会话中生效，刷新后重置。在演练场中的任何操作都不会保存到项目。

这一限制正是其价值所在。可以任意调用、直接观察场景的变化，并通过刷新恢复初始状态。在此处无法对项目造成破坏。

## 使用时机

在编写集成代码之前。[WebUI Open API](/worldbuilder/zh/docs/open-api) 允许外部应用驱动已发布的查看器，而调用能否生效，差异往往在于参数结构。在演练场中确认只需数秒，在自己的应用中确认则需要一次构建。

已完成的集成中出现异常调用时同样适用。在此复现可区分问题出在自身代码还是调用本身。

## 打开方式

选择 **Open API Playground**。它基于当前项目打开，因此调用作用的对象即为当前查看的模型、标记与界面图层。

完整的方法与参数列表，请见 [WebUI Open API 参考](/worldbuilder/zh/docs/open-api)。
