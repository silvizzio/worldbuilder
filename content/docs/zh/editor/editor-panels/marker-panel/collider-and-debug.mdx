## 碰撞体

**碰撞体**是添加到场景中、供标记与点击附着的形体。该区域列出已有的碰撞体，并提供刷新按钮与用于添加的加号按钮。为空时显示「无碰撞体」。

当仅靠模型表面不足以进行拾取时，需要添加碰撞体。细窄的栏杆、构件之间的缝隙，或扫描质量较差的区域，都会使点击缺少可靠的命中对象。碰撞体可补足这一点。

## 调试工具

| 控件 | 作用 |
| --- | --- |
| 标记位置 | 显示所选标记在场景中的位置 |
| 碰撞体 | 绘制碰撞体，使其形体可见 |

当标记在面板中显示正常，但在视口中位置错误时，请使用这两个控件。**标记位置**可显示标记实际保存的坐标，从而区分是摆放问题还是显示问题。
