标记面板中的碰撞体与调试工具，用于确认用户点击场景时实际命中的位置。它们可以帮助排查标记位置偏移、点击无响应或测量点不准确等问题。

## 碰撞体

碰撞体是添加到场景中的可命中形体，用于承载点击、标记和测量操作。当可见模型表面不足以稳定拾取时，可通过碰撞体补充命中范围。

以下情况适合使用碰撞体：

| 场景 | 说明 |
| --- | --- |
| 细小构件难以点击 | 例如栏杆、管线、边缘或薄片结构。 |
| 扫描区域质量不足 | 可见画面存在，但点击命中不稳定。 |
| 需要在虚拟区域添加标记 | 标记位置不一定对应可见模型表面。 |

面板会列出已有碰撞体，并提供刷新和新增入口。当列表为空时，会显示“无碰撞体”。

## 调试工具

| 控件 | 说明 |
| --- | --- |
| 标记位置 | 显示所选标记在场景中的实际坐标位置。 |
| 碰撞体 | 在视口中显示碰撞体形体，便于检查命中范围。 |

当标记在列表中存在，但视口位置不符合预期时，可先开启**标记位置**，确认保存坐标是否正确；再开启**碰撞体**，检查点击命中范围是否与预期一致。
