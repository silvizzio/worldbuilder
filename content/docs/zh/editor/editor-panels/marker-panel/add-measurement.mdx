---
title: 添加测量
description: 测量模型上的距离、路径长度与面积。
---

**添加测量**位于标记面板的添加标记下方。

| 工具 | 测量内容 |
| --- | --- |
| 线段 | 两点之间的直线距离 |
| 折线 | 沿一系列点的总长度 |
| 面积 | 一组点所围成的面积 |

选择工具后，在模型上点击各个点。操作过程中视口会显示提示，状态栏显示进度，例如「线段测量：已选 0 / 2 个点」。按 Esc 取消。

完成的测量显示在**测量结果**中，初始状态为「无测量结果」。垃圾桶图标可清空列表。

测量基于碰撞代理而非可见表面进行拾取。若某个点落在异常位置，请开启[显示碰撞代理](/worldbuilder/zh/docs/editor/editor-panels/model-panel/collision-proxy)查看实际命中的对象。
