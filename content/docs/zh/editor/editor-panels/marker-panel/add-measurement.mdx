添加测量用于在三维场景中获取距离、路径长度和面积信息。对于按真实比例生成的重建成果，测量结果可以辅助回答空间尺寸、设备间距、通道宽度等问题。

## 测量类型

| 工具 | 测量内容 | 所需点数 |
| --- | --- | --- |
| 线段 | 两点之间的直线距离 | 2 个点 |
| 折线 | 多个点连接后的路径总长度 | 2 个或更多点 |
| 面积 | 多个点围合形成的区域面积 | 3 个或更多点 |

## 操作步骤

1. 打开**标记面板**。
2. 在**添加测量**区域选择测量工具。
3. 根据提示在模型上依次点击测量点。
4. 完成所需点数后，系统生成测量结果。
5. 在**测量结果**中查看记录，必要时可清空结果列表。

测量过程中，视口会显示当前状态，例如“线段测量：已选 0 / 2 个点”。如需取消当前测量，可按 Esc 退出。

## 准确性说明

测量结果依赖模型比例、重建精度和碰撞代理。若模型比例未校准，或碰撞代理与可见模型不一致，测量点可能偏离目标位置。

当测量点明显落在错误位置时，建议先检查[碰撞代理](/worldbuilder/zh/docs/editor/editor-panels/model-panel/collision-proxy)或开启相关调试显示，确认实际点击命中的形体。

测量结果可用于项目评估、方案沟通和远程确认，但不应替代正式测绘成果。对精度要求较高的场景，应结合原始测绘数据或现场复核。
