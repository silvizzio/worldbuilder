标记将信息附着到特定位置或模型对象上。它们让静态的三维视图具备自我说明的能力：为资产命名、标识位置、提供巡检材料，或将运营数据与空间内容关联起来。

重建成果呈现的是空间的样貌；标记则说明观看者正在看什么、它为何重要，以及下一步该做什么。

请在资产摆放完成后再添加标记。标记会绑定到具体位置，之后若移动底层模型，就需要重新调整标记。

## 标记类型

在标记面板顶部的「添加 POI」区域中提供四种类型。

| 类型 | 承载内容 | 适用场景 |
| --- | --- | --- |
| 文本标记 | 描述、提示、注释 | 为资产命名、说明位置、在语境中突出关键信息 |
| 图片标记 | 照片、设备图像、视觉参照 | 三维模型未能体现、但位置或对象需要的视觉佐证 |
| 视频标记 | 演示、操作说明、场景记录 | 说明资产的工作方式，或展示流程与时序性语境 |
| 数据标记 | 与对象或位置关联的数值 | 将视觉场景与业务或运营信息连接起来 |

## 字段参考

标记放置完成后，其属性会显示在「基础信息」中。

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 名称 | 标记的标签，同时也是它在 POI 图层中的标识。 | 按其所描述的内容命名，使标记增多后大纲仍然可读。 |
| 样式 | 标记渲染为文本 POI 还是图标 POI，并附带颜色选择器。 | 标签需一眼可读时使用文本 POI；标记数量多、易造成画面拥挤时使用图标 POI。 |
| 缩放 | 标记在场景中的显示尺寸。 | 地图级场景中标记从远处观看，可适当调大。 |
| 位置 | 标记在三维空间中的坐标。 | 由放置操作确定，需精确落在某个特征上时可用数值微调。 |
| 高度 | 标记相对其锚点的垂直偏移。 | 将标记抬离其描述的表面，避免标签与资产重叠。 |
| 可见距离 | 标记显示所需的相机距离范围。 | 在密集场景中限制该值，使标记仅在观看者靠近相关区域时才出现。 |
| 连接线 | 是否在标记与其锚点之间绘制连线。 | 当标记被抬高、需要明确其锚点位置时启用。 |

颜色通过「样式」一行附带的 RGB 选择器设置。

<Callouts title="注意事项" cautions={['「可见距离」是避免地图级场景一打开就是一堵重叠标签墙的关键控件。在密集场景中，它值得刻意设置，而不是沿用默认值。']} />

## 添加文本标记

添加文本标记以显示描述、提示或业务注释。文本标记适合为资产命名、说明位置，并在三维语境中直接突出关键信息，让观看者无需离开空间视图即可理解某个场景元素。

## 添加图片标记

添加图片标记以提供照片、设备图像或视觉参照。

当某个位置或对象需要三维模型本身无法承载的视觉佐证时，图片标记最为实用：铭牌特写、缺陷照片、说明「本应是什么样」的参考图。重建采集的是几何形态，而非文档资料。

## 添加视频标记

添加视频标记以提供演示、操作说明或场景记录。

视频能传达静态注释无法表达的流程与先后顺序，适合说明资产的运行方式、完整展示某一流程，或记录某个时间点上的状态。

## 添加数据标记

添加数据标记以显示与空间对象或位置关联的数据。

数据标记把视觉场景与业务或运营信息连接起来，这正是数字孪生在巡检中「有信息价值」而不仅仅「还原准确」的关键。展示一台设备的模型是一张图；而附上运行数值的同一个模型，则是一个监控界面。

## 下一步

标记不止于展示。你可以为其附加动作，使点击标记时打开链接、移动相机或显示界面页面。详见[添加交互](/zh/docs/editor/editor-panels/marker-panel/add-interaction)。
