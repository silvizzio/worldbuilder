**标记**是固定在场景中某一点上的标签，作用类似地图上的图钉。它可承载文本、图片、视频或数据值，并始终附着在该位置上。

标记的作用在于补充扫描成果本身不具备的说明能力。扫描成果呈现空间的样貌，但不说明观看者正在查看什么、其重要性，以及下一步操作。标记承载这部分信息，并将其放置在观看者正在注视的位置。

请在模型摆放完成后添加标记。标记会记住所固定的位置。之后移动模型，标记将留在原处，需要手动重新定位。


## 标记类型

标记面板顶部的「添加 POI」区域提供四种类型。

| 类型 | 承载内容 | 适用场景 |
| --- | --- | --- |
| 文本标记 | 描述、提示、注释 | 为资产命名、说明位置、在语境中突出关键信息 |
| 图片标记 | 照片、设备图像、视觉参照 | 三维模型未能体现、但位置或对象需要的视觉佐证 |
| 视频标记 | 演示、操作说明、场景记录 | 说明资产的工作方式，或展示流程与时序性语境 |
| 数据标记 | 与对象或位置关联的数值 | 将视觉场景与业务或运营信息关联 |

## 字段参考

标记放置完成后，其属性显示在「基础信息」中。

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 名称 | 标记的标签，同时也是其在 POI 图层中的标识。 | 按所描述的内容命名，使标记增多后大纲仍可读。 |
| 样式 | 标记渲染为文本 POI 还是图标 POI，并附带颜色选择器。 | 标签需一眼可读时使用文本 POI；标记密度较高、影响视口清晰度时使用图标 POI。 |
| 缩放 | 标记在场景中的显示尺寸。 | 地图级场景中标记从远处观看，可适当调大。 |
| 位置 | 标记在三维空间中的坐标。 | 由放置操作确定，需精确落在特定特征上时可用数值调整。 |
| 高度 | 标记相对其锚点的垂直偏移，同行附带**连接线**复选框。 | 将标记抬离其描述的表面，并启用连接线以明确锚点位置。 |
| 可见距离 | 一对相机距离值：**显示**距离与**隐藏**距离。 | 密集场景中同时设置两者，使标记随观看者靠近而出现、远离时消失。 |

颜色通过「样式」一行附带的 RGB 选择器设置。位置以独立的 X、Y、Z 数值输入。

<Callouts title="注意事项" cautions={['「可见距离」是一对显示/隐藏距离值，而非单一阈值，因此标记可随靠近而出现、随远离而消失。该控件可避免地图级场景在加载时显示大量重叠标签。', '「连接线」位于「高度」一行旁。抬高标记而不启用该选项，标签将与其所描述的对象失去可见关联。']} />

## 添加文本标记

添加文本标记以显示描述、提示或业务注释。文本标记适用于为资产命名、说明位置，并在三维语境中直接突出关键信息，使观看者无需离开空间视图即可理解场景元素。

## 添加图片标记

添加图片标记以提供照片、设备图像或视觉参照。

当位置或对象需要三维模型本身无法承载的视觉佐证时，图片标记最为适用：铭牌特写、缺陷照片、说明应有状态的参考图。重建采集的是几何形态，而非文档资料。

## 添加视频标记

添加视频标记以提供演示、操作说明或场景记录。

视频可传达静态注释无法表达的流程与先后顺序，适用于说明资产的运行方式、完整展示某一流程，或记录特定时间点的状态。

## 添加数据标记

添加数据标记以显示与空间对象或位置关联的数据。

数据标记将视觉场景与业务或运营信息关联，使数字孪生在巡检中具备信息价值，而不仅是还原准确。设备模型呈现其几何形态；附加运行数值后的同一模型还可呈现其当前状态。

## 下一步

标记不限于展示。可为其附加动作，使点击时打开链接、移动相机或显示界面页面，详见[添加交互](/zh/docs/editor/editor-panels/marker-panel/add-interaction)。
