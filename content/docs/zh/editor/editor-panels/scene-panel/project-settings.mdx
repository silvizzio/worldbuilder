项目设置包含用于标识项目的四项数值：**标题**、**封面图**、**场景背景色**与**项目类型**。

其中三项会在编辑器之外显示。标题是项目列表中搜索所匹配的对象。封面是列表与分享链接中显示的缩略图。类型用于向打开项目的人员说明该场景的类别。背景色是唯一仅影响三维视图本身的设置。

请在创建项目时设置这四项，并在对外分享前再次确认。

## 字段参考

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 项目标题 | 项目的显示名称。 | 使用清晰的场景、资产或面向客户的名称，便于团队快速识别项目。 |
| 项目封面 | 显示在项目列表与分享入口中的缩略图。 | 选择有代表性的视角，使主要场景或资产一目了然。 |
| 场景背景 | 三维场景的背景颜色。 | 选择能与主体资产形成对比、并契合展示语境的颜色。 |
| 项目类型 | 项目类别：物体、空间或地图。 | 使类型与主要资产层级匹配，保持编辑与评审预期一致。 |

## 设置项目标题

使用**项目标题**字段更新显示名称。

[项目列表](/zh/docs/project-center/project-list)中的搜索以标题为匹配对象，因此命名决定项目后续能否被找到。包含场地、资产或客户信息的标题可一次返回正确结果；「测试 2」这类标题则不能，其代价由下一个需要该项目的人承担。

项目组合越大，这一点越重要。同批项目采用一致命名，还可使相关项目在排序时集中显示。

## 设置环境背景色

使用背景色控件调整三维场景背景，使其契合内容与评审语境。

背景色属于呈现决策，而非装饰选择。它决定资产与背景之间的对比度，而对比度决定观看者能否辨认形体与细节。深色资产置于深色背景上，无论重建质量如何，轮廓都会被削弱。

物体级、空间级与地图级场景通常需要不同处理。物体展示适合使用可凸显主体的中性背景；地图场景则需要不与地形争夺注意力的背景。

## 设置项目封面图

使用**项目封面**截取并更新显示在项目列表与分享入口中的缩略图。

封面是项目的快速识别标识。在场景外观相似的项目组合中，有代表性的封面可使评审者在打开前辨认出正确项目，避免逐个打开确认。

请从能够说明项目内容的视角截取封面，而非使用相机当前恰好对准的画面。

## 设置项目类型

使用**项目类型**选择器更改项目类别。

类型应与主要内容保持一致：物体级、空间级或地图级。该设置在创建时确定并决定了默认相机控制器，此后仍具有意义：它向打开项目的人员说明应预期何种场景，以及将采用何种导航方式。

## 这些设置的意义

项目标识使项目组合成为可管理的整体，而非一组文件。准确的标题、可辨识的封面与正确的类型，使团队能够查找、复用与复制既有成果，而非重新搭建。

每个项目的投入为几分钟，回报体现在后续环节：当未参与该项目的人员需要快速定位正确场景时。
