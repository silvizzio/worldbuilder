---
title: 灯光
description: 配置渲染模式、环境光、天空光与主光源，控制场景照明在评审与分享中如何呈现三维资产。
---

灯光决定了场景照明如何影响三维资产的呈现。通过切换渲染模式、调整环境光、启用天空光并配置主光源的方向与强度，可以改善模型在视口中的可读性。

灯光是「观看者能够巡检的资产」与「只能看看的资产」之间的分界。材质细节、表面质感，以及让人判断形体的景深线索，全都取决于光线如何落下。一份高精度采集的重建成果，若布光不当，依然可能呈现为一个扁平的剪影。

请在主要模型资产加载完成之后、项目进入最终预览或发布之前配置灯光。

## 字段参考

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 渲染模式 | 决定场景采用基于光照的渲染，还是按原始贴图与颜色显示网格材质。 | 当场景光照需要影响呈现效果时使用 **Lit**；对于需保留原始外观的扫描或烘焙贴图资产使用 **Unlit**。 |
| 环境光颜色 | 应用于场景的基础环境光颜色。 | 用于产品或资产的干净呈现时，建议使用中性色。 |
| 环境光强度 | 环境光的强度。 | 提高可增强模型整体可见度；当场景需要更强的方向性对比时应适当降低。 |
| 天空光 | 启用或关闭天空光。 | 当场景需要更柔和的环境照明时启用。 |
| 天空光颜色 | 天空光的颜色。 | 使用低饱和的冷色或中性色，避免大范围照明压过模型材质。 |
| 天空光强度 | 天空光的强度。 | 与环境光一同调整，平衡整体亮度。 |
| 主光源 | 启用或关闭主光源。 | 当资产需要更强的主光方向来体现形体与表面细节时启用。 |
| 主光源颜色 | 主光源的颜色。 | 展示物体或产品并需要自然材质高光时，使用中性或暖色调。 |
| 主光源强度 | 主光源的强度。 | 提高可强调形体与材质细节；若高光过强则应降低。 |
| 主光源水平角 | 主光源的水平方向。 | 围绕资产旋转主光，避免出现不理想的阴影方向。 |
| 主光源俯仰角 | 主光源的垂直方向。 | 控制光线来自更高还是更低的角度。 |

## 三种光源

场景照明由三部分贡献构成。理解每一部分的作用，比随意调整数值要快得多。

| 光源 | 贡献 | 缺少它会怎样 |
| --- | --- | --- |
| 环境光 | 覆盖整个场景的均匀基础光 | 阴影区域暗到无法辨认 |
| 天空光 | 大范围、柔和的环境照明 | 对比变得生硬，表面显得刺目 |
| 主光源 | 具有明确角度的单一方向性光源 | 形体扁平，表面失去立体感 |

多数场景需要这三者达成平衡：环境光建立可见度，天空光柔化画面，主光源则恢复让物体显得立体的方向性塑形。

## 配置渲染模式

使用**渲染模式**切换场景处理光照的方式。**Lit** 会将场景光照应用到模型上，使环境光、天空光与主光源的设置在视口中可见；**Unlit** 则关闭场景光照，按原始贴图或颜色显示网格材质。

如何选择，取决于资产本身已经包含了什么。扫描资产往往在采集的那一刻就把光照信息烘焙进了贴图。在已有烘焙光照之上再叠加场景光照，会得到重复、浑浊的结果，这正是重建成果在 Unlit 模式下往往观感更好的原因。

当项目需要可控的视觉呈现，或资产在制作时未烘焙光照时，Lit 模式则提供大得多的调整空间。

## 设置环境光

使用**环境光颜色**与环境光强度定义场景的基础光照水平。环境光决定整体可见度，避免暗部区域难以辨认。

对于物体级资产，适中的环境光强度能提升表面可见度而不使模型显得扁平。把它调得过高是最常见的布光错误：画面确实变亮了，但形体消失了，因为再也没有任何可辨的阴影。

对于空间或地图场景，则需在环境光、天空光与主光源之间取得平衡，以保留景深与对比度。

## 启用天空光

使用**天空光**开关启用或关闭环境照明。天空光提供范围更广、更柔和的光线，可在模型需要更均衡呈现时减弱强烈对比。

请将**天空光颜色**与强度一同调整。低饱和的冷色或中性色能在不给资产染色的前提下提供大范围照明；强度过高则会像环境光过强一样削弱景深感。

## 配置主光源

使用**主光源**开关启用或关闭主要光源。主光源决定了资产的形体塑造、表面细节的可见程度以及整体的呈现方向。

请将**主光源颜色**、强度、水平角与俯仰角一同调整。水平角控制主光围绕资产的水平位置，俯仰角控制其垂直角度，两者共同决定高光与阴影的分布，而观看者正是通过它们来读取形体的。

一个实用的起点是：把主光源偏置到一侧，而不是正对着打光。光线若从观看者正前方射来，会消除所有描述形体的阴影。

## 检查建议

灯光配置完成后，请使用与预览或分享一致的相机视角检查场景。在巡检角度下效果良好的灯光，在初始视角下可能并不成立。

灯光应服务于内容，不应遮蔽细节、造成表面过曝或产生干扰性阴影。如果观看者难以判断材质或形体，那么无论参数看上去多合理，灯光都还没有调完。

若项目使用扫描或烘焙贴图资产，请在最终确定前对比 Lit 与 Unlit 两种模式。选择取决于场景光照是提升了资产表现，还是与其原始采集外观相冲突，而这一点因资产而异。
