---
title: 灯光
description: 配置渲染模式、环境光、天空光与主光源，控制场景照明在评审与分享中对三维资产的呈现效果。
---

灯光设置控制场景的照明方式，并由此决定观看者实际能看清模型的多少细节。

采集精度本身并不能决定这一点。高精度扫描的模型若布光不当，在屏幕上仍可能呈现为扁平的形状，因为表面质感、材质与景深都取决于光线在模型上的分布方式。

请在主要模型加载完成后、项目进入预览或发布之前配置灯光。

## 字段参考

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 渲染模式 | 决定场景采用基于光照的渲染，还是按原始贴图与颜色显示网格材质。 | 场景光照需影响呈现效果时使用 **Lit**；需保留原始外观的扫描或烘焙贴图资产使用 **Unlit**。 |
| 环境光颜色 | 应用于场景的基础环境光颜色。 | 用于产品或资产的清晰呈现时，建议使用中性色。 |
| 环境光强度 | 环境光的强度。 | 提高可增强模型整体可见度；场景需要更强方向性对比时应降低。 |
| 天空光 | 启用或关闭天空光。 | 场景需要更柔和的环境照明时启用。 |
| 天空光颜色 | 天空光的颜色。 | 使用低饱和的冷色或中性色，避免大范围照明压过模型材质。 |
| 天空光强度 | 天空光的强度。 | 与环境光一同调整，平衡整体亮度。 |
| 主光源 | 启用或关闭主光源。 | 资产需要更强主光方向以体现形体与表面细节时启用。 |
| 主光源颜色 | 主光源的颜色。 | 展示物体或产品并需要自然材质高光时，使用中性或暖色调。 |
| 主光源强度 | 主光源的强度。 | 提高可强调形体与材质细节；高光过强时应降低。 |
| 主光源水平角 | 主光源的水平方向。 | 围绕资产旋转主光，避免产生不理想的阴影方向。 |
| 主光源俯仰角 | 主光源的垂直方向。 | 控制光线来自较高还是较低的角度。 |

## 三种光源

场景照明由三部分构成，了解各自的作用可显著提高调整效率。

| 光源 | 作用 | 缺少时的影响 |
| --- | --- | --- |
| 环境光 | 覆盖整个场景的均匀基础光 | 阴影区域过暗，难以辨认 |
| 天空光 | 大范围、柔和的环境照明 | 对比过强，表面呈现生硬 |
| 主光源 | 具有明确角度的单一方向性光源 | 形体扁平，表面失去立体感 |

多数场景需要三者保持平衡：环境光建立可见度，天空光柔化画面，主光源恢复使物体呈现立体感的方向性塑形。

## 配置渲染模式

使用**渲染模式**切换场景的光照处理方式。**Lit** 将场景光照应用于模型，使环境光、天空光与主光源的设置在视口中可见；**Unlit** 关闭场景光照，按原始贴图或颜色显示网格材质。

选择依据是资产自身已包含的内容。扫描资产通常在采集时即将光照信息烘焙进贴图。在已有烘焙光照之上叠加场景光照会产生重复且浑浊的结果，这也是重建成果在 Unlit 模式下往往表现更好的原因。

当项目需要可控的视觉呈现，或资产在制作时未烘焙光照时，Lit 模式提供更大的调整空间。

## 设置环境光

使用**环境光颜色**与环境光强度定义基础光照水平。环境光决定整体可见度，避免暗部区域无法辨认。

对于物体级资产，适中的环境光强度可提升表面可见度而不使模型扁平。将其调得过高是最常见的布光错误：画面变亮，但形体消失，因为不再产生可辨阴影。

对于空间或地图场景，需在环境光、天空光与主光源之间取得平衡，以保留景深与对比度。

## 启用天空光

使用**天空光**开关启用或关闭环境照明。天空光提供范围更广、更柔和的光线，可在模型需要更均衡呈现时减弱强烈对比。

请将**天空光颜色**与强度一同调整。低饱和的冷色或中性色可在不给资产染色的前提下提供大范围照明；强度过高会与环境光过强一样削弱景深。

## 配置主光源

使用**主光源**开关启用或关闭主要光源。主光源决定资产的形体塑造、表面细节可见程度与整体呈现方向。

请将**主光源颜色**、强度、水平角与俯仰角一同调整。水平角控制主光围绕资产的水平位置，俯仰角控制其垂直角度，两者共同决定高光与阴影的分布，观看者通过这一分布判断形体。

实用的起始设置是将主光源偏置到一侧，而非正对打光。光线从观看者正前方射入会消除用于描述形体的阴影。

## 检查建议

灯光配置完成后，请使用与预览或分享一致的相机视角检查场景。在巡检角度下效果良好的灯光，在初始视角下未必成立。

灯光应服务于内容，不应遮蔽细节、造成表面过曝或产生干扰性阴影。若观看者难以判断材质或形体，则无论参数如何，灯光配置尚未完成。

若项目使用扫描或烘焙贴图资产，请在最终确定前对比 Lit 与 Unlit 两种模式。选择取决于场景光照是提升了资产表现，还是与其采集时的外观相冲突，这一点因资产而异。
