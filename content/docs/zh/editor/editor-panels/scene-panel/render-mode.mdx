渲染模式位于场景面板的基础设置中，用于决定模型是否受场景灯光影响。选择正确的渲染模式，是后续灯光和画面调优的前提。

## 模式说明

| 模式 | 效果 | 适用对象 |
| --- | --- | --- |
| Lit | 场景灯光会影响模型，环境光、天空光和主光源都会参与渲染。 | 手工制作模型、未烘焙光照的模型 |
| Unlit | 场景灯光不会影响模型，模型按自身贴图和颜色显示。 | 扫描模型、已烘焙光照的资产 |

## 如何选择

如果模型来自真实场景扫描，并且贴图中已经包含光照和阴影信息，建议使用 **Unlit**。此时灯光控件不会明显改变模型外观，这是正常现象。

如果模型需要通过场景灯光塑造明暗关系，或模型本身没有烘焙光照，建议使用 **Lit**。此时可以继续通过[设置场景灯光](/worldbuilder/zh/docs/step-by-step-workflow/6-lighting)调整环境光、天空光和主光源。

## 判断方法

不确定模型类型时，可在 Lit 和 Unlit 之间切换并观察画面：

| 观察结果 | 建议选择 |
| --- | --- |
| Lit 下出现重复阴影、画面发灰或高光异常 | 使用 Unlit |
| Unlit 下模型过平、缺少体积感或无法体现材质 | 使用 Lit |
| 两种模式差异不明显 | 以展示清晰度和业务需求为准 |

扫描资产常见问题是“贴图已有光照，再叠加实时灯光”，这会造成阴影和高光重复。此类情况下，切换为 Unlit 通常能得到更自然的画面。
