**渲染模式**是场景面板**基础模式**中的第一个控件。它决定一件事：所设置的灯光是否真正作用于模型。

<ShotGrid images={['/demos/project-center/screens/scene-panel-lighting.png']} />

## 两种模式

| 模式 | 效果 |
| --- | --- |
| Lit | 场景灯光影响模型。环境光、天空光与主光源都会改变呈现效果。 |
| Unlit | 忽略场景灯光。模型按采集时的贴图与颜色显示。 |

## Unlit 的作用

扫描模型本身已包含光照信息。在为重建拍摄场地时，阳光、天空以及室内的每一盏灯都会被记录进表面颜色中。这称为**烘焙光照**，即光照是贴图的一部分，而非在观看时实时计算。

在烘焙光照之上再开启场景灯光，同一表面会出现两套阴影。高光出现在原本不存在的位置，画面因此显得浑浊，而非更明亮。

面板中也说明了这一点：Unlit 适用于扫描或烘焙贴图资产。

## 如何选择

模型来自扫描且外观已经正确时，使用 **Unlit**。此时下方的灯光控件不会产生效果，属于正常现象。

需要控制呈现效果，或模型在制作时未烘焙光照时，使用 **Lit**。多数手工制作的资产属于后者。此时[灯光](/worldbuilder/zh/docs/step-by-step-workflow/6-lighting)中的设置才会生效。

如不确定，可在两种模式之间切换并观察模型。差异会立即显现，呈现更清晰的一方即为该资产的正确选择。
