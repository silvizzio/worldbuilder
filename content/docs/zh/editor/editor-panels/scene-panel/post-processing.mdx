后处理用于优化项目的视觉输出，使三维场景在预览、分享与演示时保持一致的呈现效果。启用后，当前项目的画面参数可在同一处集中调整。

如果说灯光作用于场景，那么后处理作用于画面。它是最后一道调整层，在场景本身已经正确之后才施加，改变的是项目的观感，而不会改变底层模型资产。

请在场景、相机与模型摆放趋于稳定后再使用该模块。

## 它在工作流中的位置

| 层次 | 作用对象 | 何时应在此处解决问题 |
| --- | --- | --- |
| [灯光](/zh/docs/editor/editor-panels/scene-panel/lighting) | 三维场景本身 | 资产显得扁平、昏暗或缺乏形体 |
| 后处理 | 渲染后的画面 | 场景本身没问题，但输出缺少精致度 |

顺序很重要。后处理无法挽救一个布光糟糕的场景，它只能优化一个布光良好的场景。如果资产难以辨认，问题几乎总是出在灯光；此时先动后处理，等于在处理症状而非病因。

## 适用场景

| 情形 | 后处理的作用 |
| --- | --- |
| 准备提交外部评审 | 在评审者查看前提升整个场景的视觉一致性 |
| 灯光已正确设置但画面仍显扁平 | 调整仅靠灯光无法解决的画面级对比度与平衡 |
| 需要在多种设备上展示同一项目 | 减少不同观看条件下场景表现的差异 |
| 制作用于演示或市场推广的项目 | 补上那层将「可用场景」与「可展示成果」区分开的精致度 |

## 字段参考

后处理由该区域顶部的开关启用。开启后，各控制项按效果分组显示。

| 分组 | 字段 | 控制内容 |
| --- | --- | --- |
| — | 渲染缩放 | 场景在显示前的渲染分辨率。 |
| — | 色调映射 | 应用于渲染画面的色调映射曲线。 |
| 泛光 | 泛光强度 | 明亮区域周围光晕的强度。 |
| 泛光 | 泛光模糊级别 | 光晕从光源向外扩散的范围。 |
| 调色 | 饱和度 | 画面整体的色彩浓度。 |
| 调色 | 亮度 | 画面整体亮度。 |
| 调色 | 对比度 | 明暗区域之间的差异程度。 |
| 暗角 | 暗角强度 | 画面边缘变暗的强度。 |
| 暗角 | 暗角内径 | 暗角自画面中心向外开始出现的位置。 |
| 暗角 | 暗角外径 | 暗角达到最大强度的位置。 |
| 色散 | 色散强度 | 高对比边缘处色差的强度。 |
| TAA | 启用 TAA | 开启或关闭时间性抗锯齿。 |
| TAA | TAA 抖动 | 时间性抗锯齿所使用的亚像素偏移量。 |

## 配置后处理效果

在设置面板中启用后处理，然后调整画面参数以契合展示与评审语境。目标是提升场景可读性、视觉平衡与整体呈现质量。

请在受众实际使用的观看条件下检查后处理效果。画面级调整会改变观看者对景深、对比度与视觉焦点的感知，而在一台明亮、色彩准确的显示器上调好的场景，在会议室的笔记本电脑上可能观感迥异。如果项目将用于客户演示，请在接近现场设备的屏幕上确认一遍。

## 关于「克制」的一点提醒

后处理是编辑器中最容易做过头的环节。调参过程中看起来颇具冲击力的效果，往往在观看者第一次看到场景时显得用力过猛；而一个让人注意到「处理痕迹」的场景，会分散对它本应呈现的资产的注意力。

检验标准是：观看者注意到的是效果，还是内容。数字孪生工作的目的通常是巡检、评审或讲解，因此内容应当胜出。

## 意义

呈现质量会影响项目被认真对待的程度。同一份重建成果、同样的精度，输出看上去是「已完成」还是「半成品」，收到的反应截然不同；而这个判断往往在最初几秒内就已形成，做判断的人也并不会从技术层面去评估重建质量。

后处理只是工作流末端的一点投入，却决定了干系人形成的是上述两种印象中的哪一种。
