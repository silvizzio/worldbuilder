后处理作用于渲染后的画面，而不是直接改变模型或灯光本身。它适合在模型、相机和灯光基本配置完成后使用，用于优化最终画面的清晰度、对比度和视觉一致性。

如果模型本身难以辨认，应优先检查渲染模式和灯光设置，而不是直接调整后处理。后处理可以提升画面表现，但不能替代正确的模型摆放和布光。

## 在工作流中的位置

| 配置层级 | 作用对象 | 适合解决的问题 |
| --- | --- | --- |
| [灯光](/worldbuilder/zh/docs/step-by-step-workflow/6-lighting) | 三维场景和模型表面 | 模型昏暗、缺少形体、材质不清晰 |
| 后处理 | 渲染后的画面 | 画面偏灰、对比不足、展示效果不够精细 |

建议先完成灯光配置，再调整后处理参数。若顺序颠倒，容易用画面效果掩盖基础配置问题，导致后续在不同设备上预览时表现不稳定。

## 适用场景

| 场景 | 后处理的作用 |
| --- | --- |
| 准备提交外部评审 | 提升画面完整度和专业感 |
| 灯光正确但画面仍显平淡 | 调整对比度、亮度和色彩表现 |
| 需要在会议室或展厅演示 | 优化不同屏幕环境下的观看效果 |
| 制作客户演示版本 | 让项目从可用状态提升到可展示状态 |

## 字段参考

后处理由面板顶部开关控制。开启后，可按分组调整以下参数。

| 分组 | 字段 | 说明 |
| --- | --- | --- |
| 基础 | 渲染缩放 | 控制场景显示前的渲染分辨率，数值越高画面越清晰，但性能开销也越大。 |
| 基础 | 色调映射 | 设置渲染画面的色调映射方式，影响整体明暗和色彩过渡。 |
| 泛光 | 泛光强度 | 控制高亮区域周围光晕的明显程度。 |
| 泛光 | 泛光模糊级别 | 控制光晕向周围扩散的范围。 |
| 调色 | 饱和度 | 调整画面整体色彩浓度。 |
| 调色 | 亮度 | 调整画面整体明暗。 |
| 调色 | 对比度 | 调整亮部和暗部之间的差异。 |
| 暗角 | 暗角强度 | 控制画面边缘变暗程度。 |
| 暗角 | 暗角内径 | 控制暗角从画面中心向外开始出现的位置。 |
| 暗角 | 暗角外径 | 控制暗角达到最大强度的位置。 |
| 色散 | 色散强度 | 控制高对比边缘的色差效果。 |
| TAA | 启用 TAA | 开启或关闭时间性抗锯齿。 |
| TAA | TAA 抖动 | 设置时间性抗锯齿使用的亚像素偏移量。 |

## 配置后处理效果

1. 打开**场景面板**。
2. 进入**后处理**区域。
3. 开启后处理开关。
4. 根据展示目标调整渲染缩放、色调映射、泛光、调色、暗角和 TAA 参数。
5. 在实际展示设备或接近展示环境的屏幕上检查效果。

## 使用建议

后处理应以“不影响内容判断”为原则。观看者首先需要看清模型、标记和界面信息，其次才是画面风格。若后处理效果过强，容易分散注意力，影响项目评审和业务讲解。

对于交付、巡检和评审类项目，建议优先保证画面真实、清晰、稳定；对于展示或市场演示类项目，可在此基础上适当增强视觉表现。
