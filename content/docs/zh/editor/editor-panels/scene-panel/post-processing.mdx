后处理调整的是渲染后的画面，而非场景本身。它是最后一道视觉处理环节，在场景本身已正确的前提下施加。

这一区分在实际操作中很重要。若模型难以辨认，成因几乎都在灯光，此时调整画面只能掩盖问题。请先修正灯光，再使用后处理优化最终效果。

请在场景、相机与模型摆放趋于稳定后使用该模块。


## 在工作流中的位置

| 层次 | 作用对象 | 应在此处解决的问题 |
| --- | --- | --- |
| [灯光](/worldbuilder/zh/docs/step-by-step-workflow/6-lighting) | 三维场景本身 | 资产显得扁平、昏暗或缺乏形体 |
| 后处理 | 渲染后的画面 | 场景本身正确，但输出缺少精细度 |

顺序不可颠倒。后处理无法弥补布光不当的场景，只能优化布光良好的场景。若资产难以辨认，问题通常出在灯光，此时先调整后处理相当于处理表象而非成因。

## 适用场景

| 情形 | 后处理的作用 |
| --- | --- |
| 准备提交外部评审 | 在评审者查看前提升整个场景的视觉一致性 |
| 灯光已正确设置但画面仍显扁平 | 调整仅靠灯光无法解决的画面级对比度与平衡 |
| 需在多种设备上展示同一项目 | 减少不同观看条件下场景表现的差异 |
| 制作用于演示或市场推广的项目 | 补足使成果从可用状态达到可展示状态的精细度 |

## 字段参考

后处理由该区域顶部的开关启用。开启后，各控制项按效果分组显示。

| 分组 | 字段 | 控制内容 |
| --- | --- | --- |
| — | 渲染缩放 | 场景在显示前的渲染分辨率。 |
| — | 色调映射 | 应用于渲染画面的色调映射曲线。 |
| 泛光 | 泛光强度 | 明亮区域周围光晕的强度。 |
| 泛光 | 泛光模糊级别 | 光晕自光源向外扩散的范围。 |
| 调色 | 饱和度 | 画面整体的色彩浓度。 |
| 调色 | 亮度 | 画面整体亮度。 |
| 调色 | 对比度 | 明暗区域之间的差异程度。 |
| 暗角 | 暗角强度 | 画面边缘变暗的强度。 |
| 暗角 | 暗角内径 | 暗角自画面中心向外开始出现的位置。 |
| 暗角 | 暗角外径 | 暗角达到最大强度的位置。 |
| 色散 | 色散强度 | 高对比边缘处色差的强度。 |
| TAA | 启用 TAA | 开启或关闭时间性抗锯齿。 |
| TAA | TAA 抖动 | 时间性抗锯齿使用的亚像素偏移量。 |

## 配置后处理效果

在设置面板中启用后处理，然后调整画面参数以契合展示与评审语境。目标是提升场景清晰度、视觉平衡与呈现质量。

请在受众实际使用的观看条件下检查后处理效果。画面级调整会改变观看者对景深、对比度与视觉焦点的感知，在明亮且色彩准确的显示器上调整完成的场景，在会议室笔记本电脑上可能呈现显著差异。若项目用于客户演示，请在接近现场设备的屏幕上确认。

## 关于适度使用

后处理是编辑器中最容易过度调整的环节。调整过程中显得突出的效果，在观看者首次查看场景时往往显得过重；而使人注意到处理痕迹的场景，会分散对其本应呈现的资产的注意力。

判断标准是观看者注意到的是效果还是内容。数字孪生工作的目的通常是巡检、评审或讲解，因此内容应占据主导。

## 意义

呈现质量影响项目被对待的方式。同一份重建成果、相同精度，输出显得已完成还是未完成，会得到不同反应；而该判断通常在最初几秒内形成，做出判断的人也不会从技术层面评估重建质量。

后处理是工作流末端的少量投入，却决定干系人形成上述两种印象中的哪一种。
