**模型加载动画**位于模型面板的模型参数下方。

<ShotGrid images={['/demos/project-center/screens/model-panel-settings.png']} />

重建模型的加载需要一定时间。若没有动画，模型会突然出现，观感更接近显示异常而非加载过程。动画覆盖这段时间，向观看者说明内容正在载入。

## 字段

| 字段 | 作用 |
| --- | --- |
| 动画选择 | 模型加载时播放的动画，例如 `dissolveScan` |
| 预览 | 无需重新加载场景即可播放动画 |
| 速度 | 动画的播放速度 |
| 辉光颜色 | 动画播放期间辉光的颜色 |
| 辉光强度 | 辉光的强度 |

## 调整方法

请使用**预览**，而非重新加载。加载动画每次加载只播放一次，通过刷新检查意味着每次都要等待整个场景载入，并凭记忆对比。预览可随时重播，这是判断速度与辉光强度配合效果的唯一实用方式。

速度的判断依据是观看者，而非模型。速度过快，动画在被察觉之前即已结束，失去意义；速度过慢，则会延迟已经加载完成的场景。

辉光强度是最容易调过头的设置。它以场景背景为参照，在深色背景下合适的数值，在浅色背景下会产生过曝。请对照[配置项目设置](/worldbuilder/zh/docs/step-by-step-workflow/2-project-settings)中设定的背景色进行检查。
