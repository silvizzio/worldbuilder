模型加载动画用于优化模型载入过程中的视觉体验。对于体积较大的三维资产，加载可能需要一定时间。配置加载动画后，模型出现过程会更自然，也能减少观看者误以为画面异常的情况。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| 动画选择 | 选择模型加载时播放的动画效果，例如 `dissolveScan`。 |
| 预览 | 在不重新加载场景的情况下播放动画，用于检查效果。 |
| 速度 | 控制动画播放快慢。 |
| 辉光颜色 | 设置动画播放过程中的辉光颜色。 |
| 辉光强度 | 控制辉光效果的明显程度。 |

## 配置建议

建议优先使用**预览**功能检查加载动画，而不是反复刷新场景。预览可以快速重播动画，便于比较不同速度和辉光强度的效果。

动画速度应与模型加载感受匹配。速度过快，观看者可能察觉不到动画；速度过慢，则会拖延已经完成加载的内容。一般情况下，动画应在不打断观看节奏的前提下完成过渡。

辉光效果应根据场景背景和项目用途调整。深色背景下合适的辉光强度，在浅色背景中可能显得过亮。建议结合[配置项目设置](/worldbuilder/zh/docs/step-by-step-workflow/2-project-settings)中的背景色一起检查。

## 使用场景

| 场景 | 建议 |
| --- | --- |
| 客户演示或公开展示 | 可使用较完整的加载动画，提升展示质感。 |
| 巡检或评审类项目 | 动画应简洁，避免影响信息查看效率。 |
| 多模型场景 | 保持动画风格一致，避免不同模型加载节奏混乱。 |
