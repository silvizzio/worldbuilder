模型设置控制场景中每个模型的空间状态。每项属性都有两种设置方式：在视口中拖动可视化操作手柄以求快捷，或在参数面板中输入数值以求精确。

多数布局工作会同时用到两者：先用手柄把模型大致放到位，再用参数把它调准，在多个资产需要彼此对齐时尤其如此。

## 字段参考

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 位置 | 模型在三维场景中的位置。 | 使用操作手柄快速摆放，使用参数数值精确对齐。 |
| 旋转 | 模型的朝向。 | 使模型与道路、房间、设备方向或其他场景参照对齐。 |
| 缩放 | 模型在场景中的尺寸。 | 保持相关资产之间缩放一致，使空间关系清晰可读。 |
| 可见性 | 模型在当前场景中是否显示。 | 在评审时隐藏辅助或临时资产，而无需删除它们。 |

需先在大纲的模型图层中选中模型，其设置项才会显示。未选中任何模型时，面板会提示先选择一个模型。

## 设置模型位置

使用操作手柄或参数面板调整位置，使模型在场景中准确就位。正确的定位能保持资产之间的空间关系，这正是场景「可读」而非仅仅「堆满内容」的关键。

位置通常在模型加载完成后立即设置，并应在附加标记之前定稿——之后再移动模型，就需要逐个重新调整其上的每个标记。

## 设置模型旋转

调整旋转，使模型朝向与场景语境相符。当导入资产的朝向不符合预期，或需要与道路、房间、设备布局对齐时，这一步尤为重要。

旋转偏差在地面网格的对照下最容易被发现：一个轻微偏轴的模型会让人觉得「不对劲」，却又说不清哪里不对。

## 设置模型缩放

调整缩放以匹配空间比例与展示需求。当多个资产共处同一场景，或项目需要传达真实的空间关系时，一致性最为关键。

请结合地面网格与相机视角一同检查缩放。单独看起来正确的模型，一旦有网格作为参照，可能就会显得比例失当；而缩放误差属于最难在后期察觉的问题之一，因为眼睛会逐渐适应它一直在看的东西。

<VideoDemo src="/demos/project-center/web-videos/editor-editor-panels-model-panel-model-settings-3.mp4" poster="/demos/project-center/3.2.3模型面板-设置模型缩放.poster.jpg" />

## 设置模型可见性

根据展示、调试或交互需求调整可见性。隐藏功能可让你聚焦于特定资产而无需将其从项目中移除。

这适用于分阶段演示、前后对比，以及在配置过程中临时清理辅助资产。此处设置的是编辑状态下的可见性；界面组件还可在运行时驱动模型显隐，详见[界面交互](/zh/docs/editor/editor-panels/ui-panel/add-interaction)。
