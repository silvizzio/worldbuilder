模型设置用于控制场景中每个模型的位置、旋转、缩放与可见性。

上述每一项都有两种设置方式。在视口中选中模型后，模型周围会显示拖动手柄，直接拖动即可移动模型。该方式速度较快，但难以落在精确数值上。在模型设置面板中输入数值可以精确定位，但操作相对较慢。

多数布局工作会同时使用两种方式：先将模型拖动到大致位置，再输入数值精确对齐。


## 字段参考

| 字段 | 说明 | 推荐用法 |
| --- | --- | --- |
| 位置 | 模型在三维场景中的位置。 | 先拖动到大致位置，再输入数值精确对齐。 |
| 旋转 | 模型的朝向。 | 使模型与道路、房间、设备方向或其他场景参照对齐。 |
| 缩放 | 模型在场景中的尺寸。 | 保持相关资产之间缩放一致，使空间关系保持准确。 |
| 可见性 | 模型在当前场景中是否显示。 | 评审时隐藏辅助或临时资产，无需删除。 |

需先在大纲的模型图层中选中模型，其设置项才会显示。未选中任何模型时，面板会提示先选择模型。

## 设置模型位置

通过拖动或输入数值调整位置，使模型在场景中准确就位。正确的定位可保持模型之间的空间关系，使场景具备信息价值。

位置通常在模型加载完成后立即设置，并应在附加标记前确定：之后移动模型需重新调整其上的每个标记。

## 设置模型旋转

调整旋转，使模型朝向与场景语境一致。当导入资产的朝向不符合预期，或需与道路、房间、设备布局对齐时，需进行此项调整。

旋转偏差在地面网格的对照下最易发现，因为小角度旋转偏移在缺少参照时难以识别。

## 设置模型缩放

调整缩放以匹配空间比例与展示要求。当多个资产共处同一场景，或项目需要传达真实空间关系时，一致性最为关键。

请结合地面网格与相机视角检查缩放。单独查看时正确的模型，在网格提供参照后可能显示比例失当；缩放误差在后期难以识别，因为长时间观看会降低对比例的敏感度。

## 设置模型可见性

根据展示、调试或交互需求调整可见性。隐藏功能可聚焦于特定资产，而无需将其从项目中移除。

该功能支持分阶段演示、前后对比，以及在配置过程中临时清理辅助资产。此处设置的是编辑状态下的可见性；界面组件亦可在运行时控制模型显隐，详见[界面交互](/zh/docs/editor/editor-panels/ui-panel/add-interaction)。
