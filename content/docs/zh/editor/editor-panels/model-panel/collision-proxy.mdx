---
title: 碰撞代理
description: 为模型指定简化形体，用于拾取、测量与调试。
---

**碰撞代理**与**显示碰撞代理（调试）**位于模型面板的模型参数中。

碰撞代理是与模型一同生成的 `.collision.glb` 文件。它跟随高斯变换，默认隐藏，用于拾取、测量与调试视图。

| 控件 | 作用 |
| --- | --- |
| 碰撞代理 | 选择已生成的代理，或选择「无」 |
| 显示碰撞代理（调试） | 在视口中绘制代理，以便查看其形体 |

当标记无法落在点击位置，或测量吸附到错误表面时，请开启调试视图。点击实际命中的是代理，显示出来即可解释这一行为。
