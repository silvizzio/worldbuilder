碰撞代理是覆盖在模型上的简化形体，用于替代模型接收点击、拾取和测量操作。它通常不可见，但会跟随模型的位置、旋转和缩放变化。

对于扫描类模型，渲染出的画面未必等同于可点击的几何表面。碰撞代理可以为这些模型提供稳定的命中范围，使标记添加、距离测量和调试操作更加可靠。

## 功能说明

| 控件 | 说明 |
| --- | --- |
| 碰撞代理 | 为当前模型选择已生成的代理文件，或选择“无”。 |
| 显示碰撞代理（调试） | 在视口中显示代理形体，便于检查点击命中范围。 |

碰撞代理通常以 `.collision.glb` 文件形式与模型一起生成。配置后，用户点击模型时，系统会优先根据代理形体判断命中位置。

## 适用场景

当出现以下情况时，建议检查碰撞代理配置：

| 现象 | 可能原因 |
| --- | --- |
| 标记无法添加到目标表面 | 模型缺少可拾取的几何形体 |
| 标记位置偏离点击位置 | 碰撞代理与可见模型不一致 |
| 测量点吸附到错误位置 | 实际命中的代理形体与画面不匹配 |
| 模型部分区域无法点击 | 代理覆盖范围不完整 |

## 检查方法

1. 在模型面板中选中目标模型。
2. 找到**碰撞代理**设置。
3. 开启**显示碰撞代理（调试）**。
4. 对比代理形体与可见模型的位置和范围。
5. 如有偏差，重新选择合适的代理文件，或调整模型位置和缩放。

检查完成后建议关闭调试显示，避免代理形体遮挡模型，影响后续内容判断。
