## 什么是碰撞代理

**碰撞代理**是覆盖在模型之上的简化形体，本身不可见，代替模型接收点击。它以 `.collision.glb` 文件的形式与模型一同生成。

之所以需要它，是由重建模型的存储方式决定的。扫描成果并非具有表面的实体，而是点的集合，点击穿过时没有明确的命中对象。碰撞代理提供了这一对象。

面板中对其行为有准确说明：代理跟随高斯变换，默认隐藏，用于拾取、测量与调试视图。

## 控件

| 控件 | 作用 |
| --- | --- |
| 碰撞代理 | 为该模型选择已生成的代理，或选择「无」 |
| 显示碰撞代理（调试） | 在视口中绘制代理，使其形体可见 |

## 何时需要

以下三种现象指向此处。

标记无法落在点击位置，或落在表面之后。

测量吸附到并不位于模型上的点。

模型的某些部分点击无反应，而其他部分正常响应。

以上情况说明代理缺失、被设为「无」，或其形体与可见模型不一致。开启**显示碰撞代理（调试）**后，差异即可显现，因为此时看到的是点击实际命中的形体，而非渲染出的形体。

检查完成后请关闭调试视图。它会覆盖在模型之上，影响对其他内容的判断。
