调试工具包含两个控件。
两者都使摆放效果可被验证。

## 检查模型是否正确落位

1. 打开**模型面板**。
2. 选择**显示地面网格**。
3. 从侧面查看模型。

网格会显示在模型下方。
正确摆放的模型应贴合网格线。

在空白背景下，这类问题无法察觉。
在网格对照下则一目了然。

## 每次回到相同视角

1. 打开**模型面板**。
2. 选择**重置相机**。

视角将回到场景面板中设置的初始角度。

请在对比两个版本前使用。
否则每次检查都在不同角度下进行。

## 网格可以暴露的问题

| 问题 | 在网格对照下的表现 |
| --- | --- |
| 模型悬空 | 模型与网格线之间存在间隙 |
| 模型下陷 | 模型底部没入网格之下 |
| 缩放错误 | 模型跨越的方格数过多或过少 |
| 旋转错误 | 模型边缘与网格线呈夹角 |
