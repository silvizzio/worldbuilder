模型面板中的调试工具用于辅助检查三维内容。通过显示地面网格，用户可以判断模型是否悬空、下陷或比例异常；通过重置相机，用户可以快速回到预设初始视角。

## 显示地面网格

地面网格用于提供空间参考，帮助判断模型是否正确落位。

1. 打开**模型面板**。
2. 选择**显示地面网格**。
3. 从侧面或斜侧面查看模型。
4. 检查模型底部是否贴合网格线。

正确摆放的模型应贴合网格，既不悬空，也不下陷。对于空间级和物体级项目，地面网格尤其适合检查模型比例和高度关系。

## 重置相机

重置相机用于将视角恢复到场景面板中设置的初始视角，适合在多次调整后回到统一观察位置。

1. 打开**模型面板**。
2. 选择**重置相机**。
3. 检查视角是否回到预期的初始画面。

在对比多个模型位置、检查不同版本或准备预览前，建议先重置相机，避免因观察角度不同造成误判。

## 可发现的问题

| 问题 | 网格中的表现 | 处理建议 |
| --- | --- | --- |
| 模型悬空 | 模型底部与网格之间存在间隙 | 调整模型高度或缩放 |
| 模型下陷 | 模型底部进入网格下方 | 上移模型或检查坐标原点 |
| 比例异常 | 模型占用网格范围明显过大或过小 | 调整缩放比例 |
| 旋转异常 | 模型边缘与网格方向明显不一致 | 调整旋转角度 |

完成检查后，可根据需要关闭地面网格，避免影响后续标记和界面配置。
