调试工具包含两个使模型摆放可被核查的控件：地面网格与相机重置。

摆放效果在缺少参照时难以评估。一人认为模型悬空于地面之上，另一人认为位置正常，双方均无法确认。编辑过程中被移动过的相机会加剧这一问题，因为每次检查都在不同角度下进行，对比结果不具可比性。

请在判断摆放效果前打开地面网格，并在对比不同版本前重置相机。


## 控件参考

| 控件 | 作用 | 适用时机 |
| --- | --- | --- |
| 显示地面网格 | 在三维视口中切换参照网格的显示 | 检查模型是否悬空、偏移或处于异常高度 |
| 重置相机 | 将视角恢复为场景面板中配置的初始相机 | 相机已远离预期的检查角度 |

## 显示地面网格

切换地面参照网格，用于评估模型的位置、旋转与空间比例。

网格将主观判断转化为可核查的判断。悬空模型、垂直偏移与比例不一致在空白背景下难以察觉，在规则网格对照下则一目了然。旋转偏差同理：偏轴模型相对网格线会呈现明显错位。

该功能在物体级与空间级项目中最为适用，这类项目在预览或分享前需要可靠的布局检查。

## 重置相机

将当前视角恢复为[场景面板](/zh/docs/editor/editor-panels/scene-panel/camera-controller)中配置的初始相机。

该操作免去了近距离查看资产后手动找回原视角的过程。更重要的是，它使每次检查基于同一参照视角，不同迭代之间的对比在相同角度下进行，而非取决于相机的停留位置。

适用于模型摆放、标记设置与交互测试过程中的反复检查。
