调试工具包含两个控件，二者的存在都是为了让摆放方面的判断可以被核查，而不是停留在各执一词。

<ShotGrid images={['/demos/project-center/stills/editor-editor-panels-model-panel-debug-tools-1.jpg']} />

## 控件参考

| 控件 | 作用 | 适用时机 |
| --- | --- | --- |
| 显示地面网格 | 在三维视口中切换参照网格的显示 | 检查模型是否悬空、偏移或处于异常高度 |
| 重置相机 | 将视角恢复到场景面板中配置的初始相机 | 相机已远离预期的检查角度 |

## 显示地面网格

切换地面参照网格，以评估模型的位置、旋转与空间比例。

网格把主观判断变成了可核查的判断。悬空模型、垂直偏移与比例不一致，在空白背景下都很难看出，而在规则网格的对照下则一目了然。旋转偏差同理：偏轴的模型相对网格线会明显显得没有对齐。

该功能在物体级与空间级项目中最为实用，这类项目在预览或分享前需要可靠的布局检查。

## 重置相机

将当前视角恢复为[场景面板](/zh/docs/editor/editor-panels/scene-panel/camera-controller)中配置的初始相机。

这样就免去了近距离查看资产后手动找回原视角的麻烦。更有价值的是，它让每次检查都基于同一个参照视角，因此不同迭代之间的对比是在完全相同的角度下进行的，而不是取决于相机恰好停在哪里。

在模型摆放、标记设置与交互测试的反复检查中尤为实用。
