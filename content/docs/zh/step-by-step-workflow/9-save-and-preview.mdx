import { ShotGrid } from '@/components/docs'

保存与预览用于确认当前编辑内容是否可以进入评审或发布阶段。编辑器中的修改需要先保存，预览页面才会加载最新保存版本。

## 操作步骤

1. 点击顶部工具栏中的**保存**图标。

   <ShotGrid images={['/demos/project-center/screens/save-preview.png']} />

2. 点击**预览**图标，打开已保存版本。

   <ShotGrid images={['/demos/project-center/screens/preview.png']} />

3. 检查项目打开后的初始视角、灯光效果和模型位置。
4. 逐一点击标记和界面组件，确认内容和交互符合预期。
5. 如发现问题，返回编辑器修正后再次保存和预览。

## 检查重点

| 检查项 | 说明 |
| --- | --- |
| 初始视角 | 打开项目后是否直接看到主体内容。 |
| 模型与灯光 | 模型是否位置正确、清晰可见。 |
| 标记 | 标记位置、名称、媒体内容和交互是否正确。 |
| 界面 | 页面显示是否正常，文字和按钮是否清晰可用。 |
| 交互 | 相机飞行、页面显示/隐藏和模型显示/隐藏是否符合设计。 |

## 注意事项

预览显示的是已保存版本，不一定等于编辑器中尚未保存的实时状态。每次修改关键内容后，都应先保存再预览。

如果项目需要外部评审，建议使用预览页面完整检查一次观看路径，确认无误后再进入发布与分享步骤。
