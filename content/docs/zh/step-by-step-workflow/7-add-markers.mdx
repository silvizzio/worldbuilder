标记用于将业务信息绑定到三维场景中的具体位置。通过标记，观看者可以理解当前看到的对象、区域或设备，并进一步查看文本、图片、视频或数据内容。

## 操作步骤

1. 在顶部工具栏选择**标记**。
2. 在**添加标记**区域选择标记类型：**文本标记**、**图片标记**、**视频标记**或**数据标记**。

   <ShotGrid images={['/demos/project-center/screens/marker-text.png', '/demos/project-center/screens/marker-image.png', '/demos/project-center/screens/marker-video.png', '/demos/project-center/screens/marker-data.png']} />

3. 当面板显示“拾取就绪：请点击模型表面”时，在模型上点击需要标注的位置。
4. 在**基础信息**中输入标记名称。
5. 根据需要设置标记样式，例如文本、图标和颜色。
6. 检查标记是否出现在左侧大纲的**标记图层**中。

## 标记类型

| 类型 | 适用内容 |
| --- | --- |
| 文本标记 | 简短说明、区域名称、设备名称或注意事项。 |
| 图片标记 | 补充照片、局部细节、现场记录或说明图。 |
| 视频标记 | 操作演示、设备运行状态或过程说明。 |
| 数据标记 | 状态指标、业务数据或外部系统信息。 |

## 使用建议

添加标记前，应先确认模型位置已经稳定。模型后续移动会影响标记在场景中的相对位置，需要重新检查。

标记名称应简洁且可识别。对于数量较多的标记，建议采用统一命名方式，例如“区域-对象-信息类型”，便于在大纲中查找和维护。
