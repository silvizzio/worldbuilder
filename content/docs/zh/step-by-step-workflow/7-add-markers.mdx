---
title: 添加标记
description: 在模型的指定位置添加标签。
---

import { ShotGrid } from '@/components/docs'

1. 在顶部栏选择**标记**。

2. 在**添加标记**中选择**文本标记**、**图片标记**、**视频标记**或**数据标记**。

   <ShotGrid images={['/demos/project-center/screens/marker-panel-full.png']} />

3. 面板显示「拾取就绪：请点击模型表面」。

4. 点击模型上需要标注的位置。

5. 在**基础信息**中输入**名称**。

6. 将**样式**设为**文本**或**图标**，并选择颜色。

标记出现在模型上，并列入大纲的**标记图层**中。
