## 顺序的原因

标记固定在模型上的某一点。之后移动模型，标记会留在原处。

组件指向标记、模型或已保存的相机视角。这些对象必须先存在，组件才能指向它们。

项目类型决定相机控制器，控制器会改变编辑过程中布局的呈现方式。

## 常见问题

| 现象 | 原因 | 正确做法 |
| --- | --- | --- |
| 标记位置错误 | 添加标记后移动了模型 | 先摆放模型，再添加标记 |
| 场景打开时对着空白区域 | 未设置初始相机视角 | 分享前设置初始视角 |
| 组件点击无反应 | 其目标页面或模型已被删除 | 最后再搭建界面 |
| 评审者看到旧版本 | 分享前未保存项目 | 先保存并预览，再分享 |

## 分享前检查

| 检查项 | 确认内容 |
| --- | --- |
| 项目标题与封面 | 能够说明项目内容 |
| 初始相机视角 | 打开时对准主要对象 |
| 灯光 | 模型可见，无过曝表面 |
| 模型摆放 | 模型贴合地面网格 |
| 标记 | 每个标记都有名称与正确内容 |
| 界面 | 组件可读，所有操作有效 |
| 发布状态 | 已设为预期的访问权限 |
