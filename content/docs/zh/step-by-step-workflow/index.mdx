WORLD BUILDER 项目按固定顺序完成。该顺序不是约定，而是一条依赖链：每一步都建立在上一步已确定的结果之上。打乱顺序通常不会直接中断操作，但会导致后续返工，项目时间往往因此流失。

## 推荐工作流

| 步骤 | 目标 | 相关文档 |
| --- | --- | --- |
| 1. 创建项目 | 从模板或空白项目开始，系统自动生成默认场景与相机设置。 | [创建项目](/worldbuilder/zh/docs/step-by-step-workflow/1-create-project) |
| 2. 配置项目设置 | 设置项目标题、封面图、背景色与项目类型。 | [项目设置](/worldbuilder/zh/docs/step-by-step-workflow/2-project-settings) |
| 3. 上传或加载模型资产 | 将三维资产导入项目并整理资产结构。 | [资产管理](/worldbuilder/zh/docs/step-by-step-workflow/3-upload-models) |
| 4. 调整模型布局 | 设置位置、旋转、缩放与可见性。 | [模型设置](/worldbuilder/zh/docs/step-by-step-workflow/4-adjust-model-layout) |
| 5. 配置相机行为 | 选择控制器类型、初始视角与视场角。 | [相机控制器](/worldbuilder/zh/docs/step-by-step-workflow/5-camera-behaviour) |
| 6. 配置灯光 | 设置渲染模式、环境光、天空光与主光源。 | [灯光](/worldbuilder/zh/docs/step-by-step-workflow/6-lighting) |
| 7. 添加场景标记 | 为位置与模型附加文本、图片、视频或数据。 | [添加标记](/worldbuilder/zh/docs/step-by-step-workflow/7-add-markers) |
| 8. 添加界面页面与交互 | 创建页面、添加组件并配置交互。 | [页面与组件管理](/worldbuilder/zh/docs/step-by-step-workflow/8-ui-pages-and-interactions) |
| 9. 保存并预览 | 保存编辑内容，在发布前检查成果。 | [发布项目](/worldbuilder/zh/docs/step-by-step-workflow/9-save-and-preview) |
| 10. 发布与分享 | 按预期访问权限生成可分享入口。 | [项目操作](/worldbuilder/zh/docs/step-by-step-workflow/10-publish-and-share) |

## 三个阶段

十个步骤可分为三个阶段，建议分阶段进行，而非连续完成。

**基础配置，第 1 至 2 步。** 此阶段的决策当前成本极低，后续返工成本较高。项目类型决定相机控制器，而控制器决定后续每一个摆放决策的判断依据。

**内容搭建，第 3 至 8 步。** 工作量的主体，也是依赖关系最紧密的部分。依次完成资产摆放、标注与界面配置，每一层都附着在上一层已确定的位置之上。

**交付发布，第 9 至 10 步。** 这是两个独立决策，实际操作中常被合并。保存与预览用于确认内容正确，发布用于确定访问范围与权限。将两者区分开来，可避免未完成的场景流向客户。

## 顺序说明

**先配置项目设置，再导入资产。** 项目类型决定默认相机控制器，控制器影响对模型摆放效果的判断。在环绕相机下适用的布局，在第一人称视角下未必适用；若在摆放完成后才确定类型，需重新检查整个场景。

**先摆放资产，再添加标记。** 标记附着于位置与模型。模型移动后需逐个调整对应标记，且系统不会提示标记已失去依附对象。

**先添加标记，再配置界面。** 界面交互以标记、模型与相机视角为目标，目标须先存在。若先配置界面，则需重复配置一次。

**将预览作为检查点，而非最后一步。** 预览呈现已保存状态，是确认评审者所见内容的唯一可靠方式。建议在每次重要改动后预览，而非仅在最后预览：第 5 步发现的问题只需几分钟处理，同样的问题在第 10 步发现则需占用一个评审周期。

## 常见返工情形

| 现象 | 原因 | 规避方式 |
| --- | --- | --- |
| 布局调整后标记位置偏移 | 附加标记后移动了模型 | 先确定资产摆放，再添加标记 |
| 编辑器中效果正常，评审者查看时不符合预期 | 未刻意设置初始相机视角 | 分享前配置初始视角 |
| 界面组件指向已不存在的页面或模型 | 配置交互后重命名或删除了目标对象 | 将界面作为最后一层，建立在已确定的目标之上 |
| 评审者查看到的版本较旧 | 改动后未保存即分享 | 生成链接前先保存并预览 |

## 交付检查清单

向团队外部人员生成分享链接前，请逐项确认。该过程只需几分钟，却决定了本次评审收到的是有效反馈，还是一份已知未完成项的清单。

| 检查项 | 确认内容 |
| --- | --- |
| 项目标识 | 标题、封面图与项目类型与项目内容一致 |
| 场景初始视角 | 初始相机视角对准主要区域或资产 |
| 灯光呈现 | 资产清晰可见，无过曝或干扰性阴影 |
| 资产摆放 | 模型的位置、旋转、缩放与显隐符合预期 |
| 标记内容 | 文本、图片、视频与数据标记内容准确 |
| 界面体验 | 页面与组件可读，交互状态清晰 |
| 发布状态 | 项目已保存、已预览，访问权限设置正确 |
