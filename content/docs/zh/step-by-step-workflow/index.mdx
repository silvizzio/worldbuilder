分步工作流说明从空白项目到发布数字孪生应用的完整流程。建议按顺序完成各步骤，因为后续配置通常依赖前一步的结果。

## 十个步骤

| 步骤 | 操作内容 | 目标 |
| --- | --- | --- |
| [1. 创建项目](/worldbuilder/zh/docs/step-by-step-workflow/1-create-project) | 新建项目并选择项目类型 | 建立项目容器 |
| [2. 配置项目设置](/worldbuilder/zh/docs/step-by-step-workflow/2-project-settings) | 设置标题、封面、类型与背景色 | 完成项目基础信息 |
| [3. 上传模型](/worldbuilder/zh/docs/step-by-step-workflow/3-upload-models) | 将三维模型导入项目 | 准备三维资产 |
| [4. 摆放模型](/worldbuilder/zh/docs/step-by-step-workflow/4-adjust-model-layout) | 调整模型位置、旋转和缩放 | 确定场景空间关系 |
| [5. 设置相机视角](/worldbuilder/zh/docs/step-by-step-workflow/5-camera-behaviour) | 设置控制方式和初始视角 | 确定观看体验 |
| [6. 设置场景灯光](/worldbuilder/zh/docs/step-by-step-workflow/6-lighting) | 调整渲染模式和光照参数 | 保证模型清晰可见 |
| [7. 添加标记](/worldbuilder/zh/docs/step-by-step-workflow/7-add-markers) | 在指定位置添加业务信息 | 补充空间说明 |
| [8. 搭建界面](/worldbuilder/zh/docs/step-by-step-workflow/8-ui-pages-and-interactions) | 添加页面、组件和交互 | 构建导览和展示界面 |
| [9. 保存与预览](/worldbuilder/zh/docs/step-by-step-workflow/9-save-and-preview) | 保存项目并检查效果 | 确认发布前版本 |
| [10. 发布与分享](/worldbuilder/zh/docs/step-by-step-workflow/10-publish-and-share) | 发布项目并复制访问链接 | 完成交付或评审分享 |

## 为什么需要按顺序操作

模型是标记和界面交互的基础。模型位置确认后再添加标记，可以避免后续标记偏移；界面交互通常会指向模型、标记或指定视角，因此应在这些目标对象创建完成后再配置。

项目类型和相机控制方式也应尽早确认。它们会影响观看者进入场景后的移动方式，并影响后续视角、标记和界面的设计。

## 常见问题

| 现象 | 常见原因 | 建议处理 |
| --- | --- | --- |
| 标记位置不准确 | 添加标记后又移动了模型 | 先完成模型摆放，再添加标记 |
| 场景打开后看不到主体 | 未设置初始相机视角 | 发布前设置并保存初始视角 |
| 界面按钮点击无反应 | 目标页面、模型或视角已被删除 | 检查组件交互目标 |
| 评审者看到旧内容 | 修改后未保存或未重新发布 | 先保存并预览，再发布分享 |

## 发布前检查

| 检查项 | 确认内容 |
| --- | --- |
| 项目标题和封面 | 是否能准确识别项目内容 |
| 项目类型 | 是否符合地图级、空间级或物体级资产 |
| 初始相机视角 | 打开项目时是否对准主要内容 |
| 灯光和画面 | 模型是否清晰可见，无明显过暗或过曝 |
| 模型摆放 | 模型是否贴合地面或目标位置 |
| 标记内容 | 名称、位置、媒体和交互是否正确 |
| 界面组件 | 文本是否可读，按钮交互是否有效 |
| 发布状态 | 是否符合预期访问范围 |
