import { ShotGrid } from '@/components/docs'

上传模型用于将三维资产加入当前项目。模型导入后会出现在模型图层中，用户可以继续调整位置、旋转、缩放和可见性。

## 操作步骤

1. 打开编辑器中的**模型面板**或**资产管理**区域。

   <ShotGrid images={['/demos/project-center/screens/scene-panel-project-settings.png']} />

2. 选择**上传**。
3. 选择本地文件，或将文件拖放到上传区域。
4. 等待上传完成，确认资产卡片出现在资产管理中。
5. 在左侧大纲的**模型图层**中确认模型已加入项目。

## 上传前检查

| 检查项 | 说明 |
| --- | --- |
| 文件格式 | 确认模型格式符合平台支持范围。 |
| 文件命名 | 使用可识别的名称，便于后续选择和交互配置。 |
| 资产层级 | 确认模型属于物体、空间或地图级资产。 |
| 文件大小 | 大模型可能需要更长加载时间，应预留处理时间。 |

## 后续操作

模型上传完成后，需要继续完成位置、旋转和缩放调整。请参见[摆放模型](/worldbuilder/zh/docs/step-by-step-workflow/4-adjust-model-layout)。
