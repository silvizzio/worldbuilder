摆放模型用于确定三维资产在场景中的位置、方向和比例。模型摆放完成后，后续添加的标记、测量和界面交互都会基于当前模型位置。

## 操作步骤

1. 在左侧大纲的**模型图层**中选中模型。
2. 在三维视口中拖动模型，将其移动到大致位置。
3. 在**模型面板**中输入位置、旋转和缩放的精确数值。

   <ShotGrid images={['/demos/project-center/screens/position-model.png']} />

4. 打开**调试工具**，选择**显示地面网格**。
5. 从侧面或斜侧面查看模型，确认模型是否贴合网格。
6. 选择**重置相机**返回初始视角，检查整体效果。

## 检查标准

| 检查项 | 标准 |
| --- | --- |
| 位置 | 模型位于预期空间范围内，没有明显偏移。 |
| 高度 | 模型底部与地面或参考面贴合。 |
| 比例 | 模型尺寸与场景中其他内容关系合理。 |
| 方向 | 模型朝向符合观看和演示需求。 |

## 使用建议

建议在添加标记前完成模型摆放。若在标记创建后移动模型，需要重新检查标记位置、相机视角和相关界面交互。

对于多个模型组成的场景，应先摆放主体模型，再依次调整辅助模型。完成后统一使用地面网格检查整体空间关系。
