---
title: 摆放模型
description: 摆放每个模型并确认其位置正确。
---

import { ShotGrid } from '@/components/docs'

1. 在大纲的**模型图层**中选中模型。

2. 在视口中拖动模型，将其移动到大致位置。

3. 在**模型面板**中输入位置、旋转与缩放的精确数值。

   <ShotGrid images={['/demos/project-center/screens/model-panel-settings.png']} />

4. 在**调试工具**中选择**显示地面网格**。

5. 从侧面查看模型，确认其贴合网格。

6. 选择**重置相机**返回初始视角。

模型贴合网格线，既不悬空也不下陷。
