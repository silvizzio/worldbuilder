---
title: 配置项目设置
description: 设置项目标题、封面、类型与背景色。
---

import { ShotGrid } from '@/components/docs'

1. 在顶部栏选择**场景**。

   <ShotGrid images={['/demos/project-center/screens/2-project-settings-s1-1.png']} />

2. 在**项目设置**中编辑**项目标题**。
3. 从当前视角设置**项目封面**。
4. 选择**项目类型**：物体、空间或地图。
5. 输入**背景色**十六进制值，或从色板中选取。

标题与封面将显示在项目列表中。
