---
title: 配置项目设置
description: 设置项目标题、封面、类型与背景色。
---

import { ShotGrid } from '@/components/docs'

1. 在顶部栏选择**场景**，然后打开**项目设置**。

   <ShotGrid images={['/demos/project-center/screens/scene-panel-project-settings.png']} />

2. 编辑**项目标题**。

3. 设置**项目封面**，或删除当前封面后截取新的画面。

4. 选择**项目类型**：物体、空间或地图。

5. 通过十六进制值或色板设置**背景色**。

标题与封面将显示在项目列表中。
