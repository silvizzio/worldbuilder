项目设置用于维护项目的基础信息。这些信息会影响项目列表中的识别方式，也会影响场景打开后的视觉背景和默认体验。

## 操作步骤

1. 在顶部工具栏选择**场景**，然后打开**项目设置**。

   <ShotGrid images={['/demos/project-center/screens/scene-panel-project-settings.png']} />

2. 编辑**项目标题**。
3. 设置**项目封面**，或删除当前封面后重新截取画面。
4. 选择**项目类型**：物体、空间或地图。
5. 通过十六进制色值或色板设置**背景色**。
6. 保存项目，使设置进入预览版本。

## 字段说明

| 字段 | 说明 | 建议 |
| --- | --- | --- |
| 项目标题 | 显示在项目列表和项目管理入口中。 | 包含客户、场地、资产或版本信息。 |
| 项目封面 | 用于在项目列表中快速识别项目。 | 使用能体现项目主体的清晰画面。 |
| 项目类型 | 决定项目资产层级和默认观看方式。 | 根据物体、空间或地图级资产选择。 |
| 背景色 | 设置三维场景的基础背景颜色。 | 与模型颜色形成对比，避免主体不清晰。 |

## 命名建议

项目标题建议使用稳定格式，例如“客户名称 + 场地名称 + 版本号”或“产品名称 + 演示场景 + 日期”。清晰命名可以提升搜索效率，也便于多人协作和历史版本回溯。

封面图应尽量展示项目主体。对于空间级项目，可使用入口、主场景或全局视角；对于物体级项目，可使用完整物体外观；对于地图级项目，可使用整体区域视角。
