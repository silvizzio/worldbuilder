**插件**是顶部栏中的一个标签，与场景、模型、标记、界面并列。它包含核心编辑器之外的能力，各自独立安装。

## 可用插件

| 插件 | 作用 |
| --- | --- |
| POLYVIEW 3D | 从图片与视频重建三维模型 |
| AI Texture | 使用 AI 生成贴图与材质 |
| Reality Capture | 快速摄影测量流程 |
| Point Cloud Cleaner | 清理与裁剪点云 |
| BIM Converter | 转换与优化 BIM 格式 |

POLYVIEW 3D 标有 BETA 标识，其余插件可按需安装。

## 运行方式

已安装的插件在右侧面板中打开，占用功能面板原本的位置。左侧的大纲与中间的视口保持不变，因此插件运行期间场景仍然可见。

这一点对重建类插件尤为重要，因为单次任务可能耗时半小时，期间需要继续开展其他工作。
