---
title: 概述
description: 安装可为编辑器增加能力的插件。
---

**插件**是顶部栏中的一个标签，与场景、模型、标记、界面并列。

它包含两个视图。

| 视图 | 显示内容 |
| --- | --- |
| 我的插件 | 已安装的插件 |
| 插件市场 | 全部可用插件，每项带有安装按钮 |

撰写本文时可用的插件：

| 插件 | 作用 |
| --- | --- |
| POLYVIEW 3D | 从图片与视频重建三维模型 |
| AI Texture | 使用 AI 生成贴图与材质 |
| Reality Capture | 快速摄影测量流程 |
| Point Cloud Cleaner | 清理与裁剪点云 |
| BIM Converter | 转换与优化 BIM 格式 |

已安装的插件在右侧面板中打开，替代原有的功能面板。
