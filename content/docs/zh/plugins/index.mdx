插件是在线编辑器的扩展能力入口，与场景、模型、标记和界面并列显示。用户可以根据项目需要安装插件，用于补充核心编辑器之外的制作能力。

插件适用于需要在项目制作过程中完成额外处理的场景，例如从视频生成三维模型、生成材质贴图、处理点云或转换 BIM 文件。插件安装后会在右侧面板中打开，三维视口和左侧大纲保持可见。

## 可用插件

| 插件 | 主要用途 |
| --- | --- |
| POLYVIEW 3D | 根据图片或视频素材生成三维模型。 |
| AI Texture | 使用 AI 生成贴图和材质。 |
| Reality Capture | 提供摄影测量相关处理流程。 |
| Point Cloud Cleaner | 清理、裁剪和优化点云数据。 |
| BIM Converter | 转换并优化 BIM 文件格式。 |

其中，POLYVIEW 3D 当前带有 BETA 标识，表示该能力仍处于持续优化阶段。其他插件可根据项目素材和制作流程按需安装。

## 运行方式

已安装插件会在编辑器右侧面板中运行。插件打开时，左侧大纲和中间三维视口不会关闭，用户仍可以查看当前项目内容。

对于三维重建、点云清理等耗时任务，插件通常会在后台执行。用户可以在任务运行期间继续检查场景或处理其他配置，待任务完成后再回到插件结果中获取产物。
