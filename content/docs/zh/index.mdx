WORLD BUILDER 是基于 VIZZIO 三维重建能力构建的数字孪生内容编辑平台。平台面向地图级、空间级和物体级三维资产，提供项目管理、场景编辑、内容标注、交互配置、预览分享和 Web 集成能力，帮助团队将三维重建成果快速转化为可展示、可讲解、可交付的浏览器端应用。

三维重建成果通常具备较高的空间还原度，但在实际业务使用中仍存在门槛：查看依赖专业软件，编辑需要三维或前端开发能力，对外展示也往往需要额外搭建页面或演示环境。WORLD BUILDER 将这些流程整合到统一的网页端工作区中，非工程人员也可以完成内容配置、交互搭建、预览确认和项目发布。

## 解决的问题

从三维重建完成到业务交付，传统流程通常需要在三维软件、文档说明、前端页面和部署环境之间反复切换，协作成本高，修改周期长，交付内容也不易维护。

| 传统方式 | 使用 WORLD BUILDER |
| --- | --- |
| 三维文件需要专用软件打开 | 通过链接在浏览器中直接访问 |
| Viewer 和演示页面依赖开发人员搭建 | 在可视化编辑器中完成配置 |
| 修改内容需要重新开发或重新发布 | 支持编辑、预览、保存和再次分享 |
| 注释、说明和演示信息分散在文档中 | 信息可直接绑定到三维场景中的对应位置 |
| 不同用途需要重复制作项目 | 可基于已有项目复制、调整和复用 |

通过 WORLD BUILDER，三维重建成果不再只是一次性交付文件，而可以作为长期复用的数字资产。团队可在同一项目基础上制作不同客户版本、演示版本或更新版本，减少重复搭建工作。

## 适用角色

WORLD BUILDER 支持多角色协作。不同成员可围绕项目生命周期在各自职责范围内完成操作，并将结果自然衔接到下一环节。

| 角色 | 主要职责 | 常用功能 |
| --- | --- | --- |
| 项目负责人 | 创建项目、维护项目信息、管理访问与发布状态 | 项目中心、项目设置 |
| 三维内容运营人员 | 导入资产、调整模型位置、检查比例与对齐关系 | 模型面板、调试工具 |
| 解决方案工程师 | 添加业务标注、配置交互逻辑、搭建展示界面 | 标记面板、界面面板 |
| 评审人员与客户 | 浏览项目内容、查看演示效果并反馈意见 | 预览链接、分享链接 |
| 开发人员 | 将已发布的 Viewer 集成到业务系统中 | WebUI Open API |

平台的核心价值在于降低三维内容的使用门槛。理解业务场景的人无需掌握专业三维软件，也可以通过标记、页面和交互配置完成面向客户或内部团队的可视化表达。

## 应用场景

WORLD BUILDER 可适用于不同尺度的三维资产。资产层级不同，最终承载的业务场景也不同。

**地图级：园区、城市与基础设施展示。**
适用于规划汇报、园区展示、基础设施评估和空间态势说明。用户可以在三维地图中挂载测绘信息、规划约束、资产状态和业务说明，减少在地图、报告和现场照片之间来回查找的成本。

**空间级：建筑、室内空间与设施巡检。**
适用于远程看场、设施巡检、租户沟通和承包商协作。用户可以通过漫游视角查看建筑内部结构，并结合图片、视频和文字标记补充设备状态、巡检说明或风险提示。

**物体级：产品展示与设备培训。**
适用于产品演示、设备讲解、结构展示和培训材料制作。用户可以围绕三维物体配置视角切换、部件显示/隐藏、交互标记和语音讲解，让观看者按预设路径了解产品特点和关键结构。

无论资产规模大小，平台都可以帮助团队减少现场沟通成本，提升三维成果在展示、评审、培训和交付中的使用效率。

## 平台能力

WORLD BUILDER 的能力围绕三维资产的管理、编辑、交互和发布展开。

**端到端内容制作流程。**
平台承接 VIZZIO 的三维重建成果，支持从资产导入、场景配置、内容标注到预览发布的完整流程，减少格式转换、素材整理和页面搭建等额外工作。

**多层级三维资产管理。**
地图、空间和物体级资产可在统一框架下管理。无论是园区、建筑、房间还是单个设备，均可按照一致的方式进行项目创建、内容编辑和成果发布。

**可视化编辑工作区。**
在线编辑器将场景配置、模型管理、标记配置和界面搭建集中在同一工作区中。用户可以在三维视口中直接查看调整结果，提升配置效率和内容一致性。

**灵活的预览与发布能力。**
项目可在编辑过程中随时预览，并通过分享链接进行评审或交付。访问控制和发布状态与项目管理流程结合，便于团队在不同阶段管理可见范围和交付版本。

## 平台结构

WORLD BUILDER 主要包含两个工作区：项目中心和在线编辑器。

| 工作区 | 主要用途 | 文档入口 |
| --- | --- | --- |
| 项目中心 | 管理项目创建、项目列表、项目信息、复制、分享和发布状态 | [项目中心](/worldbuilder/zh/docs/project-center/) |
| 在线编辑器 | 配置三维场景、模型、标记、交互页面和发布内容 | [在线编辑器](/worldbuilder/zh/docs/editor/) |

此外，WebUI Open API 面向开发集成场景，提供对场景、相机、模型、标记和界面的控制能力，便于将已发布 Viewer 嵌入到自有业务系统中。

### 在线编辑器

在线编辑器用于将三维项目制作成可交互的数字孪生场景。用户可以在同一页面中查看三维视口，并通过场景面板、模型面板、标记面板和界面面板完成内容配置。

四个功能面板分别对应场景表现、资产管理、业务信息和前端交互层，能够让复杂项目保持清晰的配置结构，便于后续维护和多人协作。

<ShotGrid images={['/demos/project-center/0.2在线编辑器.jpg']} />

[查看编辑器文档](/worldbuilder/zh/docs/editor/)

### 项目中心

项目中心用于管理项目本身。每个项目包含独立的项目名称、项目类型、封面图、场景信息和发布状态。用户可以在项目中心创建、查找、复制和维护项目，适合同时管理多个演示、客户或业务场景。

## 资产层级

资产层级用于描述三维内容的规模和观看方式。创建项目时，资产层级会影响项目类型、默认相机控制方式以及最终的使用体验。

| 层级 | 内容范围 | 默认控制方式 | 典型成果 |
| --- | --- | --- | --- |
| 地图级 | 城市街区、园区、室外场地和地理环境 | 第三人称视角 | 规划评审、园区展示、基础设施说明 |
| 空间级 | 建筑、室内空间、房间和设施环境 | 第一人称视角 | 空间漫游、远程巡检、看场沟通 |
| 物体级 | 单个设备、产品、车辆或零部件 | 第三人称视角 | 产品演示、设备培训、结构讲解 |

地图级和物体级场景通常从外部观察，因此更适合第三人称视角；空间级场景需要进入内部移动和查看，因此默认采用第一人称视角。用户也可以根据项目需要调整相机控制方式。
