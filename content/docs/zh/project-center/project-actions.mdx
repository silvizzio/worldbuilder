项目操作控制项目本身：更新、复制、分享与删除。编辑器控制项目内部的内容。

这些操作容易与编辑器内部的保存、预览与发布操作混淆，后者记录在[发布项目](/zh/docs/editor/project-actions)中。

两者的区分基于职能：

- **编辑器**控制项目内容
- **项目中心**控制项目本身

## 操作参考

| 操作 | 作用 | 适用时机 |
| --- | --- | --- |
| 编辑项目 | 更新项目名称、封面图与基础信息，或在编辑器中打开项目 | 项目信息需更新，或需继续进行场景搭建 |
| 复制项目 | 创建项目副本，复用其场景结构与配置 | 搭建相似场景、准备备选版本，或在重大修改前保留基线 |
| 分享项目 | 生成分享链接或发布入口，并设置访问权限 | 评审人员或客户需在编辑器之外查看项目 |
| 删除项目 | 从项目组合中移除该项目 | 项目已结束使用 |

## 编辑项目

使用**编辑项目**更新项目名称、封面图或基础信息，或在编辑器中重新打开该项目。

准确的项目信息是在列表中定位项目的前提，忽视这一点的代价将由下一个需要该项目的人承担。请在分享给评审人员之前更新，使干系人看到的名称与封面与实际内容一致。

## 复制项目

使用**复制项目**复制已有项目，包括其场景结构与配置。

这项能力直接影响团队成本的增长方式。已完成的项目即为可用基线：场景设置已调优、资产已摆放、标记已撰写、界面已搭建。复制并改造用于新客户、新场地或更新后的采集成果，是从该基线开始，而非从空场景开始。

它也是进行重大改动的稳妥方式。先复制，再修改副本，原项目保持完整，可用于对比或回滚，从而消除项目后期面对大幅修改时的顾虑。

| 适用情形 | 替代方式 |
| --- | --- |
| 同一场景面向新客户的变体 | 重新搭建场景并重新添加标记 |
| 同一场地的更新采集成果 | 新建项目并重新配置全部内容 |
| 可能回退的结构调整 | 直接修改原项目 |
| 供评审对比的备选版本 | 仅展示单一版本 |

## 分享项目

使用**分享项目**生成分享链接。可根据查看范围，将访问权限设置为关闭、公开访问或密码保护。

| 访问设置 | 适用情形 | 需注意 |
| --- | --- | --- |
| 关闭 | 进行中的项目，仅限内部使用 | 链接存在，但接收方无法访问内容 |
| 公开 | 开放演示、市场推广、对外发布 | 持有链接者均可打开项目 |
| 密码保护 | 客户评审、涉及商业敏感信息的项目 | 需通过其他渠道向接收方提供密码 |

对外分享前请先保存并预览。分享链接呈现已保存状态，因此无论编辑器当前显示什么内容，评审者打开的都是最后一次保存的版本。

<VideoDemo src="/demos/project-center/share-project.mp4" poster="/demos/project-center/share-project.poster.jpg" />

## 删除项目

使用**删除项目**移除不再需要的项目，保持列表聚焦。

删除前请确认该项目是否仍需用于历史查证、客户演示或版本对比。复制的成本很低，而已被取代的项目往往是特定时间点内容的唯一记录。
