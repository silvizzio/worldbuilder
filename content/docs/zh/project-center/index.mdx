项目中心是用户登录后进入的项目管理工作区，用于统一管理团队内的数字孪生项目。用户可以在这里创建项目、查找项目、复制项目，并进入编辑器继续配置具体内容。

当项目数量较少时，项目管理的成本并不明显。但随着客户、场地、采集批次和演示版本不断增加，项目列表会迅速扩展。项目中心通过项目标识、搜索排序和复制能力，帮助团队保持项目组合的可查性和可复用性。

## 项目中心的作用

项目中心管理的是项目本身，而不是项目内部的三维内容。它解决的是“项目如何创建、如何查找、如何复用、如何分享”的问题。

| 能力 | 说明 | 文档 |
| --- | --- | --- |
| 项目创建 | 从空白项目开始，选择项目类型并初始化基础场景。 | [创建项目](/worldbuilder/zh/docs/step-by-step-workflow/1-create-project) |
| 搜索与排序 | 根据关键词、创建时间或修改时间定位目标项目。 | [项目列表](/worldbuilder/zh/docs/project-center/project-list) |
| 项目复制 | 基于已有项目创建副本，用于客户版本、评审版本或更新版本。 | [发布与分享](/worldbuilder/zh/docs/step-by-step-workflow/10-publish-and-share) |
| 分享与访问 | 设置项目访问状态，并获取可用于评审或交付的访问链接。 | [发布与分享](/worldbuilder/zh/docs/step-by-step-workflow/10-publish-and-share) |

## 与在线编辑器的关系

项目中心和在线编辑器属于同一工作流中的两个阶段。项目中心负责项目级管理，在线编辑器负责项目内部内容创作。

| 项目中心 | 在线编辑器 |
| --- | --- |
| 创建、查找、复制和删除项目 | 配置场景、模型、标记和界面 |
| 管理项目名称、类型、封面和发布状态 | 调整相机、灯光、模型位置和交互 |
| 管理访问权限和分享链接 | 保存、预览和发布项目内容 |
| 面向项目组合管理 | 面向单个项目的内容制作 |

从项目中心打开项目后，系统会加载该项目已保存的编辑状态。离开编辑器前请先保存，未保存的修改不会进入预览或发布版本。

## 关于项目复制

项目复制适用于需要复用既有结构的场景，例如为不同客户制作演示版本、为同一场地保留多个评审版本，或基于更新后的采集成果制作新版项目。

复制项目可以保留已有的场景结构、模型布局、标记和界面配置，使团队从可用基础上继续调整，而不是每次从空白项目开始。对于多客户、多场地或多轮评审的项目，复制能力可以显著降低重复配置成本。

建议在进行重大调整前先复制项目，再在副本中修改。这样既可以保留原始版本，也便于对比不同方案。
