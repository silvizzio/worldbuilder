---
title: Publish and Share
description: Publish the project as a link and set who can open it.
---
import { ShotGrid } from '@/components/docs'

1. Confirm the project is saved and previewed.
2. Select the share icon in the top bar.
3. The **Publish Project** dialog opens on **Publish as link**.

   <ShotGrid images={['/demos/project-center/screens/10-publish-and-share-s3-1.png']} />

4. Set **Publish status** to **Public access**.
5. Select **Copy** next to **Access link**, or scan the **QR code**.

The access link opens the project in any browser, with no software to install.
