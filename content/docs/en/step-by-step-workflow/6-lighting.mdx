---
title: Light the Scene
description: Light the models so shape and material are visible.
---
import { ShotGrid } from '@/components/docs'

1. Select **Scene** in the top bar, then open **Lighting**.

   <ShotGrid images={['/demos/project-center/screens/lightning.png']} />

2. Under **Base Mode**, set **Render Mode** to **Lit**.

3. Set **Ambient Color** and its value until shadowed areas are visible.

4. Turn on **Sky Light**, then set **Sky Light Color** and its value.

5. Turn on **Key Light**, then set **Key Light Color** and its value.

6. Set **Key Light Yaw** and **Key Light Pitch** to move the light to one side.

The model shows visible shadows and surface texture, not a flat shape.
