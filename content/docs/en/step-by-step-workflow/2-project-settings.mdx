---
title: Configure Project Settings
description: Set the project title, cover, type, and background colour.
---

import { ShotGrid } from '@/components/docs'

1. Select **Scene** in the top bar, then open **Project Settings**.

   <ShotGrid images={['/demos/project-center/screens/scene-panel-project-settings.png']} />

2. Edit **Project Title**.

3. Set **Project Cover**, or delete the current one and capture a new view.

4. Choose **Project Type**: Object, Space, or Map.

5. Set **Background Color** by hex value or from the swatch.

The title and cover now appear in the project list.
