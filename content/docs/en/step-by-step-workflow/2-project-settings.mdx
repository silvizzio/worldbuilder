---
title: Configure Project Settings
description: Set the project title, cover, type, and background colour.
---

import { ShotGrid } from '@/components/docs'

1. Select **Scene** in the top bar.

   <ShotGrid images={['/demos/project-center/screens/2-project-settings-s1-1.png']} />

2. Under **Project Settings**, edit **Project Title**.
3. Set **Project Cover** from the current view.
4. Choose **Project Type**: Object, Space, or Map.
5. Enter a **Background Color** hex value, or pick one from the swatch.

The title and cover now appear in the project list.
