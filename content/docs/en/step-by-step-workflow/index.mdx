Work the ten steps in order. Each step uses something the step before it set up.

## The ten steps

| Step | What you do |
| --- | --- |
| [1. Create a Project](/worldbuilder/en/docs/step-by-step-workflow/1-create-project) | Start a project and choose its type |
| [2. Configure Project Settings](/worldbuilder/en/docs/step-by-step-workflow/2-project-settings) | Set title, cover, type, and background colour |
| [3. Upload Models](/worldbuilder/en/docs/step-by-step-workflow/3-upload-models) | Bring 3D models into the project |
| [4. Position Models](/worldbuilder/en/docs/step-by-step-workflow/4-adjust-model-layout) | Place each model and check it sits correctly |
| [5. Set the Camera View](/worldbuilder/en/docs/step-by-step-workflow/5-camera-behaviour) | Choose how viewers move and what they see first |
| [6. Light the Scene](/worldbuilder/en/docs/step-by-step-workflow/6-lighting) | Light the models so shape and material are visible |
| [7. Add Markers](/worldbuilder/en/docs/step-by-step-workflow/7-add-markers) | Pin labels to points on the model |
| [8. Build the Interface](/worldbuilder/en/docs/step-by-step-workflow/8-ui-pages-and-interactions) | Add pages and components on top of the scene |
| [9. Save and Preview](/worldbuilder/en/docs/step-by-step-workflow/9-save-and-preview) | Save and check the result |
| [10. Publish and Share](/worldbuilder/en/docs/step-by-step-workflow/10-publish-and-share) | Publish as a link and set access |

## Why the order matters

A marker is pinned to a point on a model. Move the model afterwards and the
marker stays where it was.

A component points at a marker, a model, or a saved camera view. Those have to
exist before a component can point at them.

The project type sets the camera controller, and the controller changes how the
layout looks while you work on it.

## Common problems

| What you see | Why | What to do instead |
| --- | --- | --- |
| Markers sit in the wrong place | The model moved after the markers were added | Position models before adding markers |
| The scene opens on empty space | The initial camera view was never set | Set the initial view before sharing |
| A component does nothing | Its target page or model was deleted | Build the interface last |
| A reviewer sees an old version | The project was not saved before sharing | Save and preview, then share |

## Before you share

| Check | Confirm |
| --- | --- |
| Project title and cover | They describe the project |
| Initial camera view | It opens on the main subject |
| Lighting | Models are visible, with no blown-out surfaces |
| Model placement | Models rest on the ground grid |
| Markers | Each one has a name and the right content |
| Interface | Components are readable and every action works |
| Publish status | Set to the access level you intend |
