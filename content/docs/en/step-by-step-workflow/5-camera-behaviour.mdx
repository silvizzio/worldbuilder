---
title: Set the Camera View
description: Choose how viewers move, and what the scene shows when it opens.
---

import { ShotGrid } from '@/components/docs'

1. Select **Scene** in the top bar, then open **Camera Controller**.

   <ShotGrid images={['/demos/project-center/screens/5-camera-behaviour-s1-1.png']} />

2. Set **Controls** to Third-person (Orbit) for objects and maps, or first person for interiors.
3. Set **Camera FOV**. The default is 75.
4. Set **Pitch Limits** to stop viewers looking too far up or down.
5. Set **Spring Arm Distance Limits** to control how far viewers can zoom.
6. Move the camera in the viewport to the angle you want.
7. Under **Set Initial View**, capture the current **Initial Camera Position** and **Initial Camera Rotation**.

Reload the scene. The first frame now shows the main subject.
