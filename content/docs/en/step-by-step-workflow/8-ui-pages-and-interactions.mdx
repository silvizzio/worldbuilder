---
title: Build the Interface
description: Add pages and components on top of the scene.
---

import { ShotGrid } from '@/components/docs'

1. Select **UI** in the top bar.

   <ShotGrid images={['/demos/project-center/screens/8-ui-pages-and-interactions-s1-1.png']} />

2. Under **Canvas Settings**, turn off **Enable interaction** so you do not move the camera by accident.
3. Set **Width** and **Height**, or choose **16:9**, **4:3**, or **1:1**.
4. Turn on **Lock Canvas Size** to keep it fixed while you work.
5. Under **Page Management**, select the plus button to create a page.

   <ShotGrid images={['/demos/project-center/screens/8-ui-pages-and-interactions-s5-1.png']} />

6. Add components to the page: buttons, text, images, or audio.

   <ShotGrid images={['/demos/project-center/screens/8-ui-pages-and-interactions-s6-1.png', '/demos/project-center/screens/8-ui-pages-and-interactions-s6-2.png', '/demos/project-center/screens/8-ui-pages-and-interactions-s6-3.png']} />

7. Select a component, then **Add Interaction**, then choose an action.

   <ShotGrid images={['/demos/project-center/screens/8-ui-pages-and-interactions-s7-1.png', '/demos/project-center/screens/8-ui-pages-and-interactions-s7-2.png']} />


Clicking a component now moves the camera, switches pages, or hides a model.
