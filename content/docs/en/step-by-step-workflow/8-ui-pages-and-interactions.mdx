---
title: Build the Interface
description: Add pages and components on top of the scene.
---
import { ShotGrid } from '@/components/docs'

1. Select **UI** in the top bar.

2. Under **Page Management**, select the plus button to add a page.

   <ShotGrid images={['/demos/project-center/screens/ui-panel-page-and-webpage.png']} />

3. Enter a **Name** and tick **Visible by default** if the page should show on load.

4. Under **Add Components**, choose **Add Web Page**, **Add Text Button**, **Add Image Button**, **Add Text**, **Add Image**, or **Add Audio**.

5. For a text button, set **Button text**, **Font size (px)**, **Color**, **Background color**, and **Opacity (0~1)**.

   <ShotGrid images={['/demos/project-center/screens/ui-panel-text-button.png']} />

6. For an image button, set **Button text** and choose a file in **Image picker**.

   <ShotGrid images={['/demos/project-center/screens/ui-panel-image-button.png']} />

7. For text, enter the **Text** and set **Font size (px)** and **Color**.

   <ShotGrid images={['/demos/project-center/screens/ui-panel-text.png']} />

8. For an image, choose a file in **Image picker**.

   <ShotGrid images={['/demos/project-center/screens/ui-panel-image.png']} />

9. For audio, choose a file in **Audio picker**, then set **Autoplay**, **Loop**, and **Volume (0~1)**.

   <ShotGrid images={['/demos/project-center/screens/ui-panel-audio.png']} />

10. Set **X(px)**, **Y(px)**, **Width (px)**, and **Height (px)** for each component.

11. Under **Layout**, set **Horizon** and **Vertical** so the component holds its place when the screen size changes.

12. On a button, open the **Interaction Panel** and select **Add Interaction**.

The page appears under **UI Layer** in the Outline, with each component listed beneath it.
