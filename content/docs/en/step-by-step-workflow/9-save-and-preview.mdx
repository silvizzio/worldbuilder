---
title: Save and Preview
description: Save the project and check it before publishing.
---
import { ShotGrid } from '@/components/docs'

1. Select the save icon in the top bar.

   <ShotGrid images={['/demos/project-center/screens/save-preview.png']} />

2. Select the preview icon to open the saved version.

   <ShotGrid images={['/demos/project-center/screens/preview.png']} />

3. Check the opening view, the lighting, and the marker positions.

4. Click each component and confirm it does what you expect.

5. Return to the editor, fix anything wrong, and save again.

The preview shows the saved version, which is what a reviewer will open.
