---
title: Create a Project
description: Start a new project and choose its type.
---
import { ShotGrid } from '@/components/docs'

1. Open the **Project Center**.

   <ShotGrid images={['/demos/project-center/screens/1-create-project-s1-1.png']} />

2. Select **Create a New Project**.

   <ShotGrid images={['/demos/project-center/screens/1-create-project-s2-1.png']} />

3. Choose the project type: **Object**, **Space**, or **Map**.
4. Select **Create**.

The project opens in the editor. The top bar shows Scene, Model, Marker, UI, and Plugins.
