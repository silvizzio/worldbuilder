---
title: Position Models
description: Place each model and check it sits correctly.
---

import { ShotGrid } from '@/components/docs'

1. Select the model under **Model Layer** in the Outline.

2. Drag it in the viewport to move it roughly into place.

3. Enter exact values in the **Model Panel** for position, rotation, and scale.

   <ShotGrid images={['/demos/project-center/screens/model-panel-settings.png']} />

4. Select **Show Ground Grid** under **Debug Tools**.

5. Look at the model from the side and check it rests on the grid.

6. Select **Reset Camera** to return to the opening view.

The model rests on the grid line, not floating above or sinking below it.
