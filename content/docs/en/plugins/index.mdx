**Plugins** is a tab in the top bar, beside Scene, Model, Marker, and UI. It
holds capabilities that are not part of the core editor, each installed
separately.

<ShotGrid images={['/demos/project-center/screens/plugin-marketplace.png']} />

## The two views

| View | What it shows |
| --- | --- |
| My Plugins | The plugins already installed |
| Marketplace | Everything available, with an Install button on each |

## What is available

| Plugin | What it does |
| --- | --- |
| POLYVIEW 3D | Reconstruct 3D models from images and videos |
| AI Texture | Generate textures and materials with AI |
| Reality Capture | Fast photogrammetry workflow |
| Point Cloud Cleaner | Clean and crop point clouds |
| BIM Converter | Convert and optimize BIM formats |

POLYVIEW 3D carries a BETA label. The others install on demand.

## How they behave

An installed plugin opens in the right-hand panel, in the space the feature
panels normally occupy. The Outline on the left and the viewport in the middle
stay as they are, so the scene remains visible while the plugin works.

That matters for the reconstruction plugins in particular, since a job can take
half an hour and you will want to keep working in the meantime.
