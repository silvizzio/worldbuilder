The Project Center is where WORLD BUILDER work starts and ends. It handles project creation, portfolio browsing, search, sorting, and the project-level actions that move a project through its lifecycle.

A project here is more than a file record. It carries the project identity, cover image, type, scene configuration, publishing state, and the access settings that decide who can open it. Managing that centrally is what keeps a portfolio navigable once several scenarios are in progress at once.

## Why the portfolio layer exists

A single project does not need a management layer. Twenty do.

Teams delivering digital twin work accumulate projects faster than expected: a version per customer, a version per site, a version per capture date, plus the experiments that turned out well enough to keep. Without a portfolio view, finding the right one becomes guesswork, and the common failure is rebuilding something that already exists because nobody could locate it.

The Project Center addresses this with three capabilities that compound: identity that makes a project recognisable, search and sorting that make it findable, and duplication that makes it reusable.

## Relationship to the editor

The Project Center and the Online Editor are two halves of one workflow, split along a clean line: the Project Center manages projects as objects, the editor manages what is inside them.

| Project Center | Online Editor |
| --- | --- |
| Creating, finding, duplicating, deleting | Scene settings, assets, markers, UI |
| Project identity, type, cover image | Camera behaviour, lighting, layout |
| Access control and share links | Save, preview, publish |
| Operates across many projects | Operates inside one project |

Opening a project from the Project Center loads it into the editor with its saved state intact. Save before navigating away, because unsaved editor changes are not carried across.

## A note on duplication

Duplication is the most underused capability here, and the one that changes how a team's costs scale.

A project whose structure is understood can be copied and adapted for a new customer, a new site, or an updated capture, starting from a working baseline rather than an empty scene. That applies to alternate versions during a review cycle too: duplicate before a significant change, edit the copy, and the original remains available for comparison or rollback.

The alternative, rebuilding each time, is where the cost of a 3D programme usually accumulates without anyone deciding it should.
