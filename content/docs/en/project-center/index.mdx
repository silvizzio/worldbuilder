The **Project Center** is the screen you land on first.
It holds every project in your workspace and keeps them findable as that list grows.

One project needs no management layer, and twenty do.
Teams accumulate projects faster than they expect: one per customer, one per site,
one per capture date, plus the experiments that turned out worth keeping.
Once the list is long enough, finding the right project becomes guesswork,
and the usual result is rebuilding something that already exists.

Three capabilities prevent that, and each one depends on the one before it:

## What a project holds

More than a file record. Each project carries:

- Project identity and cover image
- Project type
- Scene configuration
- Publishing state
- Access settings that determine who can open it

Managing that centrally is what keeps a portfolio navigable once several scenarios run in parallel.

## Relationship to the editor

Two halves of one workflow, divided along a clean line. The Project Center manages projects as objects. The editor manages what is inside them.

| Project Center | Online Editor |
| --- | --- |
| Creating, finding, duplicating, deleting | Scene settings, assets, markers, UI |
| Project identity, type, cover image | Camera behaviour, lighting, layout |
| Access control and share links | Save, preview, publish |
| Operates across many projects | Operates inside one project |

Opening a project from the Project Center loads it into the editor with its saved state intact.
Save before navigating away, since unsaved editor changes are not carried across.

## A note on duplication

The most underused capability here, and the one that changes how a team's costs scale.

A project whose structure is understood can be copied and adapted, starting from a working baseline rather than an empty scene:

- A new customer variant of the same scene
- An updated capture of the same site
- An alternate version prepared for a review

The same applies before any significant change. Duplicate first, edit the copy, and the original stays available for comparison or rollback.

The alternative is rebuilding each time, which is generally where the cost of a 3D programme accumulates without anyone having decided it should.
