Choose the project type with care.
It sets the default camera controller, which shapes every placement decision that follows.

Project creation is the entry point for a digital twin scene and takes under a minute.
Everything else generated at creation is a baseline you refine later.

## Steps

1. In the Project Center, start a new project.

2. Choose a **template** or a **blank project**.

3. Select the **project type**. This sets the default camera controller.

4. Confirm creation. A default scene and camera configuration are generated, and the project opens in the editor.

## Template or blank

| Start from | When it fits | What you get |
| --- | --- | --- |
| Template | The scene follows a pattern your team builds regularly | A standardised structure, less repeated setup |
| Blank | The scene structure is unusual or not yet decided | An empty scene, full control, more configuration |

- **Producing similar deliverables repeatedly**: use templates
- **First project, or an unfamiliar scenario**: blank avoids inheriting a structure you then have to unpick

## What project type decides

| Project type | Default controller | Suits | Why |
| --- | --- | --- | --- |
| Object | Third person | External viewing, spatial inspection, object-level presentation | Objects are examined from outside, so orbit navigation matches the intent |
| Map | Third person | Map-level presentation, urban context, infrastructure review | Wide scenes are read from above and around, not walked through |
| Space | First person | Interior walkthroughs, room-scale navigation | Interiors are entered, so walkthrough navigation matches how people understand them |

The question is how a viewer should move.
Getting it right at creation is not critical, since the setting can be changed, but it affects every placement decision afterwards.

## After creation

The generated settings exist so the project opens into something usable, not something finished.
Refine them once assets are loaded and the scene can be judged properly:

- [Project Settings](/en/docs/editor/editor-panels/scene-panel/project-settings): title, cover, background, type
- [Camera Controller](/en/docs/editor/editor-panels/scene-panel/camera-controller): controller, initial view, FOV

Tuning a camera against an empty scene is guesswork.

## Why this matters

Pairing project types with sensible defaults removes repetitive setup that adds nothing.
Project creators start from a working configuration and direct their attention to asset layout, interaction design, and review preparation.

Across a portfolio, that saving repeats on every project.
See [Project Actions](/en/docs/project-center/project-actions) for duplication, which extends the same principle to entire finished projects.
