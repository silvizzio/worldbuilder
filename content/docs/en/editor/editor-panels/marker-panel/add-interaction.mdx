An interaction is an action a marker performs when a viewer clicks it.
A marker can open an external page, move the camera to a saved viewpoint, or show a UI page.

Without an interaction, a marker only labels its position, and the viewer decides where to go next.
With one, the marker itself moves them to the relevant content.

## How interactions are configured

Each marker has an **Interaction Panel** in its edit view.
Select **Add Interaction**, then choose an action type from the dropdown.

A marker can hold more than one interaction.

They appear in the panel as Interaction 1, Interaction 2, and so on, and each can be removed on its own.

| Action | What happens on click | Use it for |
| --- | --- | --- |
| Open link | Opens an external page, business system, or document | Specifications, reports, external dashboards, supporting materials |
| Fly to view | Moves the camera to a predefined position over a set duration | Guiding viewers to the best angle for inspecting a model or area |
| Show UI panel | Shows or hides a specified UI page | Revealing contextual information or controls only when relevant |

**Fly to view** stores the camera position you want to arrive at, along with the duration of the movement.
A longer duration moves the camera smoothly, which helps the viewer follow where they are going.
A short duration cuts almost directly to the new position, and viewers can lose track of where they now are.

## Open link

Connects a marker with an external page, business system, or supporting document.

This keeps detailed information accessible without crowding the scene.
It matters when a marker references material too large to display in place: full specifications, a maintenance history, a live dashboard.

## Fly to specified viewpoint

Clicking the marker moves the camera to a predefined position.

This guides viewers to the best angle for inspecting a model, location, or area, and removes manual camera movement during a walkthrough.

<VideoDemo src="/demos/project-center/web-videos/editor-editor-panels-marker-panel-add-interaction-2.mp4" poster="/demos/project-center/3.3.2标记面板-飞行到指定视角.poster.jpg" />

## Show UI panel

Shows or hides a specified UI page, so scene elements can drive UI content.

Markers reveal contextual information, controls, or supporting panels only when relevant, which combines 3D spatial context with 2D presentation without overloading the viewport.

The target UI page must exist first.
Build pages in [Page & Component Management](/worldbuilder/en/docs/step-by-step-workflow/8-ui-pages-and-interactions) before wiring this up.
