Markers attach information to specific positions or model objects. They are what turn a static 3D view into something that explains itself: naming assets, identifying locations, providing inspection material, or associating operational data with spatial content.

A reconstruction shows what a space looks like. A marker explains what the viewer is looking at, why it matters, and what to do next.

Add markers after assets are placed. A marker is bound to a position, so moving the underlying model afterwards means revisiting the marker.

## Marker types

Four types are available from the Add POI section at the top of the Marker Panel.

| Type | Carries | Use it for |
| --- | --- | --- |
| Text Marker | Descriptions, prompts, annotations | Naming assets, explaining locations, highlighting information in context |
| Image Marker | Photos, equipment images, visual references | Evidence a location or object needs that the 3D model does not show |
| Video Marker | Demonstrations, instructions, scene records | Explaining how an asset works, or showing a process or time-based context |
| Data Marker | Values associated with an object or location | Connecting the visual scene to business or operational information |

## Field reference

Once a marker is placed, its properties appear under Basic Info.

| Field | Description | Recommended usage |
| --- | --- | --- |
| Name | The marker's label and its identifier in the POI Layer. | Name markers for what they describe, so the Outline stays readable as they accumulate. |
| Style | Whether the marker renders as a Text POI or an Icon POI, with a colour picker. | Use Text POI when the label must be readable at a glance; Icon POI when many markers would crowd the view. |
| Scale | The marker's display size in the scene. | Increase for map-level scenes where markers are viewed from a distance. |
| Position | The marker's location in 3D space. | Set by placement, adjust numerically when a marker needs to sit precisely on a feature. |
| Height | The marker's vertical offset from its anchor point. | Raise a marker clear of the surface it describes so the label does not overlap the asset. |
| Visible Distance | The camera distance within which the marker displays. | Limit it in dense scenes so markers appear only as a viewer approaches the relevant area. |
| Link line | Whether a connecting line is drawn between the marker and its anchor point. | Enable when a raised marker needs its anchor made explicit. |

Colour is set through an RGB picker attached to the Style row.

<Callouts title="Notes" cautions={['Visible Distance is the control that prevents a map-level scene from opening as a wall of overlapping labels. It is worth setting deliberately rather than leaving at its default in dense scenes.']} />

## Add text marker

Add a text marker to display descriptions, prompts, or business annotations. Text markers suit naming assets, explaining locations, and highlighting information directly in the 3D context, so viewers understand a scene element without leaving the spatial view.

## Add image marker

Add an image marker to provide photos, equipment images, or visual references.

These are most useful when a location or object needs visual evidence the 3D model itself does not carry: a close-up of a serial plate, a photograph of a defect, a reference image of how something should look. Reconstruction captures geometry, not documentation.

## Add video marker

Add a video marker to provide demonstrations, instructions, or scene records.

Video communicates procedure and sequence that a static annotation cannot. It suits explaining how an asset operates, showing a process end to end, or recording the state of something at a point in time.

## Add data marker

Add a data marker to display data associated with a spatial object or location.

Data markers connect the visual scene to business or operational information, which is what makes a digital twin informative during inspection rather than merely accurate. A model that shows a piece of equipment is a picture; the same model with its operating values attached is a monitoring surface.
