---
title: Collider and Debug Tools
description: Add colliders, and check where a marker actually sits.
---

Two sections at the bottom of the Marker Panel.

## Collider

Lists the colliders on the scene, with a refresh button and a plus button to add
one. The empty state reads "No colliders".

A collider gives a marker something to attach to when the model surface alone is
not enough to pick reliably.

## Debug Tools

| Control | What it does |
| --- | --- |
| Marker Position | Show where the selected marker sits in the scene |
| Collider | Draw the colliders so you can see their shape |

Use these when a marker looks correct in the panel but appears in the wrong place
in the viewport.
