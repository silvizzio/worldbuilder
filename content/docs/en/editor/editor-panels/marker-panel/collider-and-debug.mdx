Two sections at the bottom of the Marker Panel, both concerned with the same
question: where does a click actually land?

## Collider

A **collider** is a shape added to the scene that markers and clicks can attach
to. The section lists the colliders present, with a refresh button and a plus
button to add one. When empty it reads "No colliders".

You add one when the model surface alone is not enough to pick against. A thin
railing, a gap between parts, or a region a scan captured poorly all give clicks
nothing reliable to hit. A collider fills that in.

## Debug Tools

| Control | What it does |
| --- | --- |
| Marker Position | Show where the selected marker sits in the scene |
| Collider | Draw the colliders so their shape is visible |

Use these when a marker looks correct in the panel but appears in the wrong place
in the viewport. **Marker Position** shows you the coordinates the marker
actually holds, which separates a placement problem from a display one.
