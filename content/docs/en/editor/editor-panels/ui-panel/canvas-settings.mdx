The **canvas** is the flat working surface you arrange interface elements on,
drawn on top of the live 3D scene.

While positioning interface elements, you can accidentally drag the 3D camera or change the zoom. The scene behind the canvas can also make it harder to judge the layout.

Use these settings to lock scene interaction, hide the rendered scene or hold the canvas zoom steady while you work. They affect the editing workspace only; the published project is unchanged.

## Field reference

| Field | Description | Recommended usage |
| --- | --- | --- |
| 3D Scene Interaction | Whether your mouse still controls the 3D scene behind the interface. | Turn it off while building the interface, so you stop moving the camera by accident. |
| 3D Scene Rendering | Whether the 3D scene is visible behind the UI canvas. | Hide while refining layout, then show again for complete experience review. |
| Canvas Zoom | Whether the interface can be zoomed in and out while you work. | Lock it during detailed layout so spacing stays consistent as you judge it. |

## Enable or disable 3D scene interaction

Locks mouse interaction with the 3D scene so the view and model selection stay put while you edit UI layers.

Without it, positioning a component near the canvas edge often ends in an accidental camera drag.
That moves the scene and changes the visual context you were designing against.

## Show or hide 3D scene rendering

Hide the scene to focus on pages and component layout. Useful when scene content visually competes with UI elements.

Switch it back on before judging the result:

- **Hidden**: good for positioning
- **Visible**: necessary for evaluating readability, since contrast against the actual scene is part of what makes a component legible

An interface reviewed against a blank canvas can look clear in the editor and be difficult to read in the published project.

## Lock or unlock canvas zoom

Prevents accidental scaling while editing components.

A stable zoom level keeps the design view consistent and makes spacing easier to judge.
Spacing judged at one zoom level and checked at another produces inconsistent results, which matters most when finalising composition or aligning multiple elements.
