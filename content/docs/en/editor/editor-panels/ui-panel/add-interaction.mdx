Attach actions to UI components so the interface drives the 3D scene.
A component can move the camera, switch pages, or control model visibility.

Without them, a viewer navigates manually and finds the content themselves.
That works for exploration and fails for demonstration.


## How interactions are configured

Each component has an **Interaction Panel** in its properties.
Use **Add Interaction** to attach an action and select its type from the dropdown.
Components can carry multiple interactions, listed as Interaction 1, Interaction 2, and so on.

| Action | What happens on click | Use it for |
| --- | --- | --- |
| Fly to view | Moves the camera to a predefined viewpoint over a set duration | Guided tours, product demonstrations, planned spatial sequences |
| Show or hide UI | Shows or hides a specified UI page | Multi-step presentations, contextual information display |
| Show or hide model | Shows or hides a specified model | Staged explanations, before-and-after comparisons, simplifying complex scenes |

**Fly to view** takes camera parameters for the destination pose and a duration controlling the transition.
Keep durations consistent across a sequence of buttons so the pace of a walkthrough stays even.

## Fly to specified viewpoint

Clicking a component moves the camera to a predefined viewpoint.

This lets viewers jump directly to important assets, areas, or review angles.
It suits guided tours, product demonstrations, and any workflow where the viewer should follow a planned sequence rather than explore freely.

## Show or hide UI

Controls which content is visible at each step.

Showing only the relevant page reduces clutter and makes each stage easier to follow.
This is the mechanism behind multi-step presentations: a button advances the sequence by hiding the current page and revealing the next.

## Show or hide model

Shows or hides a specified model based on the process, scenario state, or presentation step.

This focuses attention on the assets that matter at a given moment. It supports:

- Staged explanations
- Before-and-after comparisons
- Revealing internal components by hiding the outer shell, often the clearest way to explain how something is assembled
