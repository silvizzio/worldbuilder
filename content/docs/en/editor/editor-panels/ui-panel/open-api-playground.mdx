---
title: Open API Playground
description: Try the embedded APIs against the current scene.
---

**Open API** sits in the UI Panel, between Canvas Settings and Page Management.

The panel describes it as embedded APIs for camera, models, POIs, and UI layers,
and states that changes are session-only and reset on refresh. Nothing you do
there is saved to the project.

Select **Open API Playground** to open it.

Use it to check what a call does before wiring it into a real integration. For
the full reference, see
[WebUI Open API Reference](/worldbuilder/en/docs/open-api).
