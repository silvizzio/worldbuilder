**Open API** sits in the UI Panel, between Canvas Settings and Page Management.

<ShotGrid images={['/demos/project-center/screens/ui-panel-canvas.png']} />

The panel describes it as embedded APIs for camera, models, POIs, and UI layers,
and states plainly that changes are session-only and reset on refresh. Nothing
you do in the playground is saved to the project.

That constraint is the point. You can call anything, watch what happens to the
scene in front of you, and reload to start clean. There is no way to damage the
project from here.

## When to use it

Before writing integration code. The
[WebUI Open API](/worldbuilder/en/docs/open-api) lets an external application
drive a published Viewer, and the difference between a call that works and one
that does not is often a parameter shape. Finding that out in the playground
takes seconds. Finding it out in your own application takes a build.

Also when a call is behaving unexpectedly in an integration you have already
built. Reproducing it here separates a problem in your code from a problem in the
call itself.

## Opening it

Select **Open API Playground**. It opens against the current project, so the
models, markers, and UI layers you are looking at are the ones the calls will
act on.

For the full list of methods and their parameters, see
[WebUI Open API Reference](/worldbuilder/en/docs/open-api).
