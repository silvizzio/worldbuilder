---
title: Model Loading Animation
description: Set how a model appears when the scene opens.
---

**Model Loading Animation** sits in the Model Panel, below Model Parameters.

| Field | What it does |
| --- | --- |
| Animation Selection | The animation played as the model loads, for example `dissolveScan` |
| Preview | Play the animation without reloading the scene |
| Speed | How fast the animation runs |
| Glow Color | The colour of the glow during the animation |
| Glow Strength | How strong that glow is |

Use **Preview** to check the result. Reloading the whole scene to see a loading
animation is slower and harder to compare.
