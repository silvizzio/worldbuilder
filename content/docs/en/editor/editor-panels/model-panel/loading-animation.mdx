**Model Loading Animation** sits in the Model Panel, below Model Parameters.

<ShotGrid images={['/demos/project-center/screens/model-panel-settings.png']} />

A loading animation controls how a model appears when the scene opens.

## The fields

| Field | What it does |
| --- | --- |
| Animation Selection | The animation played as the model loads, for example `dissolveScan` |
| Preview | Play the animation without reloading the scene |
| Speed | How fast the animation runs |
| Glow Color | The colour of the glow while the animation plays |
| Glow Strength | How strong that glow is |

## Setting it

Use **Preview** to replay the animation without reloading the scene. Adjust Speed and Glow Strength, then preview again to compare the result.

Speed is a judgement about the viewer, not the model. Too fast and the animation
finishes before anyone registers it, which defeats the purpose. Too slow and it
delays a scene that has already loaded.

Keep Glow Strength low enough that model details remain visible. It is measured against
the scene background, so a value that looks right on a dark background will bloom
on a light one. Check it against the background colour set in
[Configure Project Settings](/worldbuilder/en/docs/step-by-step-workflow/2-project-settings).
