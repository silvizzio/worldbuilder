Model Settings control the position, rotation, scale, and visibility of every model in the scene.

Each of these can be set two ways. Selecting a model in the viewport shows drag handles
around it, and dragging those moves the model directly.
That is the faster method, but it rarely lands on an exact value.
Entering numbers in the Model Settings panel is precise and slower to work with.

Most layout work uses both. Drag the model roughly into place, then enter values to align it exactly.


## Field reference

| Field | Description | Recommended usage |
| --- | --- | --- |
| Position | Where the model sits in the scene. | Drag it into place, then enter values to align it exactly. |
| Rotation | The model's orientation. | Align models with roads, rooms, equipment direction, or other scene references. |
| Scale | The model's size in the scene. | Keep scale consistent across related assets so spatial relationships remain accurate. |
| Visibility | Whether the model is shown in the current scene. | Hide supporting or temporary assets during review without deleting them. |

Click a model in the list on the left, under Model Layer, before its settings appear.
With nothing selected, the panel asks you to pick one.

## Set model position

Correct positioning preserves the spatial relationships between assets, which is what makes a scene informative rather than merely populated.

Two timing rules:

- Set position immediately after a model is loaded
- Settle it before markers are attached, since moving a model afterwards means revisiting every marker on it

## Set model rotation

Adjust rotation so the model's orientation matches the scene context.
This matters when imported assets do not face the intended direction, or need to align with roads, rooms, or equipment layouts.

Turn on the ground grid to spot rotation problems.
A model turned a few degrees off looks fine on its own, and visibly crooked against grid lines.

## Set model scale

Consistency matters most when several assets share a scene, or when the project needs to communicate realistic spatial relationships.

Review scale alongside the ground grid and camera view.
A model that appears correct in isolation may be wrongly proportioned once the grid provides a reference.
Scale errors are hard to catch late, because prolonged viewing reduces sensitivity to proportion.

## Set model visibility

Hiding lets you focus on specific assets without removing them from the project. It supports:

- Staged presentations
- Before-and-after comparisons
- Temporarily clearing supporting assets during configuration

Visibility set here is the editing state.
UI components can also drive model visibility at runtime, covered in [UI Interactions](/en/docs/editor/editor-panels/ui-panel/add-interaction).
