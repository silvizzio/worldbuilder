Debug Tools contains two controls that make model placement verifiable: a ground grid and a camera reset.

Placement is difficult to assess without a reference. One person sees a model floating above
the ground, another sees it sitting correctly, and neither view can be confirmed.
A camera that has been moved during editing compounds this, because each check happens
from a different angle and the comparisons are not equivalent.

Turn on the grid before judging placement, and reset the camera before comparing one version against another.


## Control reference

| Control | What it does | Use it when |
| --- | --- | --- |
| Show Ground Grid | Toggles a reference grid in the 3D viewport | Checking whether a model is floating, offset, or placed at an unexpected height |
| Reset Camera | Restores the view to the initial camera configured in the Scene Panel | The camera has moved far from the intended review angle |

## Show Ground Grid

Against an empty background these problems are nearly invisible.
Against evenly spaced grid lines they show up straight away:

- Floating models
- Vertical offsets
- Inconsistent scale
- Rotation errors, since an off-axis model is visibly misaligned relative to the grid lines

Most useful for object-level and space-level projects, where layout review needs to be reliable before preview or sharing.

## Reset Camera

Restores the current view to the initial camera configured in the [Scene Panel](/en/docs/editor/editor-panels/scene-panel/camera-controller).

Two benefits:

- Returns the view without manually navigating back after inspecting an asset up close
- Gives every check the same reference view, so comparisons between iterations happen from an identical angle
