Debug Tools has two controls.
Both make placement something you can verify.

## Check whether a model sits correctly

1. Open the **Model Panel**.
2. Select **Show Ground Grid**.
3. Look at the model from the side.

The grid appears under the models.
A correctly placed model rests on the grid line.

Against an empty background these problems are invisible.
Against a grid they show up at once.

## Return to the same view every time

1. Open the **Model Panel**.
2. Select **Reset Camera**.

The view returns to the opening angle set in the Scene Panel.

Use this before comparing two versions.
Otherwise each check happens from a different angle.

## What the grid reveals

| Problem | How it looks against the grid |
| --- | --- |
| Model floats | A gap between the model and the grid line |
| Model sinks | The base disappears below the grid |
| Wrong scale | The model spans too many or too few squares |
| Wrong rotation | Edges run at an angle to the grid lines |
