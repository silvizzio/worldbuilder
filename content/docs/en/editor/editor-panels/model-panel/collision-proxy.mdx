## What a collision proxy is

A **collision proxy** is a simplified shape that sits invisibly over a model and
catches clicks on its behalf. It arrives as a `.collision.glb` file generated
alongside the model.

The reconstructed point cloud does not provide a solid surface for clicks to hit. The proxy supplies that surface for picking, measurements and marker placement, while the point cloud provides the visible model.

The panel describes the behaviour precisely: the proxy follows the Gaussian
transform, is hidden by default, and is used for picking, measuring, and the
debug view.

## The controls

| Control | What it does |
| --- | --- |
| Collision Proxy | Choose a generated proxy for this model, or None |
| Show collision proxy (debug) | Draw the proxy in the viewport so its shape is visible |

## When you need it

Check the collision proxy if a marker lands behind the surface, a measurement snaps away from the model or clicks work on some parts but not others.

In each case the proxy is either missing, set to None, or shaped differently from
the model you can see. Turn on **Show collision proxy (debug)** and the mismatch
becomes visible, because you are then looking at the shape your clicks are
actually hitting rather than the one being rendered.

Turn the debug view off once you have finished. It draws over the model and makes
everything else harder to judge.
