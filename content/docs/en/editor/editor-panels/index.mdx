The editor is divided into four **feature panels**, and each one owns a different layer of the scene.
You switch between them by task while staying in the same workspace.

The division follows the way a digital twin is actually assembled.
You bring in the models, then set how the scene is viewed, then label what is in it,
then build the interface a viewer clicks.
Putting all of that in a single panel would mean every setting competing for attention at once.

Because the panels are separate, two people can work in the same project without colliding.
Someone positioning models does not touch interaction logic,
and someone building the interface does not need to understand model alignment.

## Panel reference

| Panel | What it configures | When you reach for it |
| --- | --- | --- |
| Scene Panel | Project title, cover, background, type, camera controller, lighting, post-processing | Establishing how the project is identified, and how the scene opens and presents |
| Model Panel | Asset upload and loading, position, rotation, scale, visibility, debug tools | Building the 3D content that forms the foundation of the scene |
| Marker Panel | Text, image, video, and data markers, plus their interactions | Attaching business context to positions and objects |
| UI Panel | Canvas behaviour, pages, components, and component interactions | Building the 2D control and presentation layer over the scene |

## Scene Panel

Controls the overall 3D scene presentation and viewing experience. It determines:

- How the project is identified in the portfolio
- What a viewer sees the moment the scene opens
- How illumination presents the assets
- How the final image appears during preview and sharing

Most settings here are configured early and refined once assets are in place.

| Module | Configures |
| --- | --- |
| [Project Settings](/worldbuilder/en/docs/step-by-step-workflow/2-project-settings) | Title, cover image, background colour, project type |
| [Camera Controller](/worldbuilder/en/docs/step-by-step-workflow/5-camera-behaviour) | Controller type, initial view, field of view |
| [Lighting](/worldbuilder/en/docs/step-by-step-workflow/6-lighting) | Render mode, ambient, sky light, key light |
| [Post Processing](/worldbuilder/en/docs/editor/editor-panels/scene-panel/post-processing) | Image-level visual refinement |

## Model Panel

Manages 3D model assets: upload and loading, parameter adjustment, and debug tools for positioning.

This is the foundation layer.
Everything above it, markers and UI interactions alike, attaches to positions established here, which is why placement is worth settling before moving on.

| Module | Configures |
| --- | --- |
| [Asset Management](/worldbuilder/en/docs/step-by-step-workflow/3-upload-models) | Upload, load, delete, batch operations |
| [Model Settings](/worldbuilder/en/docs/step-by-step-workflow/4-adjust-model-layout) | Position, rotation, scale, visibility |
| [Debug Tools](/worldbuilder/en/docs/editor/editor-panels/model-panel/debug-tools) | Ground grid, camera reset |

## Marker Panel

Adds markers and interactions for information display, navigation logic, or business context.

A scan shows what a space looks like.
It does not tell anyone what they are looking at.
A marker is a label pinned to a spot in the scene, and it carries that missing explanation.

| Module | Configures |
| --- | --- |
| [Add Marker](/worldbuilder/en/docs/step-by-step-workflow/7-add-markers) | Text, image, video, and data markers |
| [Add Interaction](/worldbuilder/en/docs/editor/editor-panels/marker-panel/add-interaction) | Open link, fly to viewpoint, show UI panel |

## UI Panel

Builds 2D UI layers on top of the 3D scene: canvas size and scaling, page and component layout, and interaction settings.

This layer turns a scene into an application.
Pages, buttons, media, and interactions let a viewer follow a defined route instead of navigating freely and hoping to find what matters.

| Module | Configures |
| --- | --- |
| [Canvas Settings](/worldbuilder/en/docs/editor/editor-panels/ui-panel/canvas-settings) | Scene interaction lock, scene rendering, canvas zoom |
| [Page & Component Management](/worldbuilder/en/docs/step-by-step-workflow/8-ui-pages-and-interactions) | Pages, buttons, text, images, audio, alignment |
| [Add Interaction](/worldbuilder/en/docs/editor/editor-panels/ui-panel/add-interaction) | Fly to viewpoint, UI visibility, model visibility |
